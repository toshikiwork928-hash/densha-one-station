# 景観の地図データ（OpenStreetMap）

作成日: 2026-10-08。堺〜なんばの線路沿いの景観を、OpenStreetMap（OSM）のデータに基づく配置にした（段階A）。完全な再現ではなく、配置・密度・道路の並走・緑地・ランドマークの位置を実物に寄せる。

## 出典

© OpenStreetMap contributors（ODbL 1.0）。Overpass API で取得。国土地理院の地図は使っていない。

## 手順

```bash
npm run osm:scenery -- --course=namba            # 取得（Overpass）→ 変換 → src/data/osm/namba.json
npm run osm:scenery -- --course=namba --offline  # 取得済みのキャッシュ（node_modules/.cache/osm/）から変換だけ
npm run osm:scenery -- --course=namba --endpoint=https://overpass.kumi.systems/api/interpreter  # 別のサーバー
```

- クラウドの開発環境からは Overpass へ接続できないことがある（相手側で切断される）。その場合はローカルで実行してデータをコミットする。
- 生データ（数十MB）は `node_modules/.cache/osm/` に置き、コミットしない。コミットするのは簡略化したデータ（約0.7MB）だけ。

## 取得するもの（線路の両側 320m）

建物、道路（幹線〜生活道路）、公園・庭園・運動場、草地・森・墓地・社寺の敷地、水面・川、学校、社寺。線路は `name` に「南海本線」を含む `railway=rail`、駅は `railway=station` の駅名。

## コースの座標への写し方

1. 線路（上下線・複々線）の点を駅間ごとに 10m の区切りで平均し、中心線を作る。
2. 各点を中心線へ射影し、中心線に沿った距離 c と、符号付きの横距離 d（進行方向の右が正）を得る。
3. c は駅の中心どうしの間で線形に伸縮して、ゲームの s（ホームの中心の s）に合わせる。コースの線形（`src/route/routes/namba.ts`）も OSM の線路形状を駅間ごとに営業キロへ伸縮して作ってあり、同じ写し方になる。
4. 横位置は d に、ゲーム側の本線群（上下本線・複々線の緩行線）の中心の横位置を足す。

## データの形（`src/data/osm/<course>.json`）

| キー | 中身 |
|---|---|
| `buildings` | `[s, lat, 長さ, 幅, 角度(度), 階数, 種類]`。外接長方形。種類は h 戸建て / a 集合住宅 / c 商業・事務所 / i 工場・倉庫 / r 社寺 / p 学校・公共 / g 車庫・小屋。階数は `building:levels`・`height` から、無ければ種類と面積から推定 |
| `roads` | `[等級, 幅, 名前, s,lat の並び]`。等級 1 = 国道・幹線、2 = 主要地方道・一般道（紀州街道など）、3 = 生活道路 |
| `areas` | `[種類, s,lat の並び]`。park / grass / pitch / school / grave / shrine / wood / water。線路から ±320m の帯で切ってある |
| `landmarks` | 名前のある大きな建物・社寺・公園・池の `[名前, s, lat]`（位置の確認用） |

## 描画（`src/world/osm-town.ts`）

- 線路から 55m 以内の戸建て・アパート・商店・マンションは `town-jp.ts` の部品（窓・ベランダ・看板）で作り、550m まで描く。それ以外は箱と屋根だけで 1.6km まで描く。
- 線路（高架・ホーム・追加の線路）にかかる建物、専用モジュールの敷地（`route.reserved`: なんばの駅ビル・なんばパークス・住ノ江検車区・七道の商業施設・住吉大社の本宮）は置かない。
- 道路・公園・森・池・墓地は地面に貼る。森・社寺・公園・墓地には木を植える（上限 1100 本）。幹線道路には街路樹。
- 下り（なんば → 堺）は `world/namba-frame.ts` の写しで同じ物理位置に描く。
- このコースでは、手続き生成の住宅列・線路沿いの道路と、素材のビル（市街地・遠景）を置かない（遠景のビル群はデータの範囲の外 340m から）。
- 乱数は `ctx.rng` を使わない。

## ランドマーク

- なんばパークス風の段々の建物: 西側（OSM のパークスタワー・住宅棟の位置）へ移した（`world/namba-terminal.ts`）。
- 住吉大社（`world/sumiyoshi-taisha.ts`）: 西の大鳥居、池と反橋、参道と石灯籠、本宮4棟（住吉造の直線の切妻屋根・朱と白・千木と鰹木）と瑞垣。位置は OSM の本宮・池から。森は OSM の森の多角形に木を植える。

## 段階B（堺〜泉大津・泉大津〜岸和田）

- データ: `sakai-izumiotsu.json`（元のコース `shiokaze` = 泉大津 → 堺）、`izumiotsu-kishiwada.json`（`kishiwada` = 泉大津 → 岸和田）。
- 走るコースへの写し方（`osmFor`）: データの元のコースと走るコースの共通の駅の中心をそろえて s を写し、逆向きなら横位置を鏡像（lat' = 左右の線路の和 − lat）にする。区間をつないだ通しコース（堺〜岸和田）は、つなぎ目の泉大津の駅の中心で各データを切って重ならないようにする。下り・通しコースでも同じ物理位置になる。
- 浜寺公園の松林（OSM の森の多角形）、紀州街道の並走、沿線の住宅。
- OSM に建物がほとんど登録されていない区間（春木〜和泉大宮など。道路は登録されている）は、道路・公園・水面を避けて戸建て中心に補う（100m ごと・片側で OSM の建物が 12 棟未満の所）。
- 地上区間では、駅舎・駅前（ホームの前後 25m、線路から 34m。待避線のある駅は 54m）、駅直結のタワー、道路の跨線橋、阪堺線・高師浜線の高架の敷地に建物・道路を置かない。地上の線路を横切る道路は線路の手前で切る（踏切は `crossings.ts`）。
- 建物はすべての線路（本線・追加の線路・2面4線駅の待避線）の中心から 4.5m 以上、外形で離す（`npm run verify:clearance` で違反 0）。
