## 工事による年代差

- [大阪府: 高石市の連続立体交差事業](https://www.pref.osaka.lg.jp/o130330/otori/jigyouinfo/04karute08.html): 高石・羽衣周辺の本線高架化と、高師浜線の2024年4月6日運行再開を確認できる。
- [南海: 高師浜線高架化](https://www.nankai.co.jp/news/231221.html): 羽衣南側の施工写真、高師浜線全線の高架化を掲載。
- [堺市: 浜寺地域の事業概要](https://www.city.sakai.lg.jp/shisei/toshi/rittaisuishin/honsen/gaiyo.html): 石津川以北は高架化済み。浜寺公園・諏訪ノ森は高架化工事中で、完成予定は2034年3月末。
- [南海: 2025年7月26日の仮線切替](https://www.nankai.co.jp/news/250625.html): 諏訪ノ森〜羽衣の下り仮線に関する説明。
- 浜寺公園の公式駅ページは2026年10月2日現在、諏訪ノ森は2024年11月16日現在の構内図を掲載。浜寺公園のPDFには1・2・4番線が記され、工事前の3面4線構成と同一ではない。
- ゲームでは指定の高架7駅・地上3駅を維持。仮線・工事の全段階、歴史的駅舎の正確な移設位置、上下ホームの細かなずれまでは再現していない。

## 交差構造物・景観

- [泉大津市: 市内見どころマップ](https://www.city.izumiotsu.lg.jp/material/files/group/1/midokoromapura.pdf) は助松JCT・堺泉北有料道路・阪神高速湾岸線・南海線の地域配置を示す。松ノ浜〜北助松、北助松〜高石の道路横断はユーザー指定を採用。道路名、交差位置、幅は実測未確認のため架空名と概形で描画。
- [堺市・南海: 阪堺線対応の地元説明資料](https://www.city.sakai.lg.jp/shisei/toshi/rittaisuishin/honsen/zentainagare.files/setumeisiryou.pdf) の7〜8ページに南海・阪堺の交差部。浜寺公園〜諏訪ノ森間で路面電車線が南海の上を横断するモチーフに使用。資料の古い完成工程は現在の工事日程として使わない。
- [堺市: 連続立体交差事業の資料](https://www.city.sakai.lg.jp/shisei/gyosei/chogi/chogiyoshi_h29/chougigijiyoushi_290525.files/0525anken2.pdf) に石津川左岸の仮橋梁写真。ゲームの鉄橋は石津川付近を参考にした演出で、実物の支間長・鋼材断面・仮橋と本橋の構造を厳密に写していない。ホームとの干渉を避け、みなと川のホーム先に配置する。
- 羽根町からの支線は高師浜線をモチーフにした高架線の描画だけ。運転コースには含めない。分岐曲率・描画延長はゲーム用。

描画位置（往路のs）: 道路1590m/2680m、路面電車跨線6310m、鉄橋中心8005m（区間7930〜8080m）、支線4980m。
これらは該当駅間に置いた概形値。道路・路面電車のlengthは線路を横断する描画全長、鉄橋150m・支線900mも実測長ではない。
線形は緩い曲線、地盤は平坦、高架面は9mで近似。実地形の標高データや地理座標をインポートしていない。
沿岸の背景も概形。西側の海は線路から900m以遠、工業地帯は約400〜650mに置く。実際の海岸線・施設の配置を写したものではない。
東側の低丘は2.6km以遠、約20〜65mの低い起伏で近似。空の稜線も東側だけに薄く低く描き、進行方向と海側を高い山で囲まない。復路では海・丘の左右を反転して地理的な側を維持する。

## 終着の速度照査

泉大津・堺は実際には本線の途中駅。ゲームの終着扱いを理由に車止めを置かない。
往復ともコース終着前に低速進入の連続速度照査を設ける。
これはゲーム用ATSの設定。実路線の保安装置の設置位置・照査速度・閉そく割りを再現したものではない。

## 再生成

`npm run timetable -- --shiokaze-only` で汐風線だけの時刻表を生成する。
普通・急行・特急、往路・復路それぞれで、勾配・分岐器制限・終着速度照査を含めて走行時間を計算する。
山岳線の時刻表はこのオプションでは変更しない。
