## 配線の根拠（配線略図.net 南海本線の図）

出典: [配線略図.net 南海本線](https://www.haisenryakuzu.net/documents/pr/nankai/main/) の `figures/011_02.svg`（堺）・`011_03.svg`（湊〜羽衣）・`011_04.svg`（高石〜泉大津）。SVG の線分・矩形の座標から読んだ。図は左が難波側、上の線が和歌山方面（下り）で、ゲームの「上り（泉大津→堺）」は図の下側の線。

- 泉大津・高石: 本線2線の外側に副線が膨らみ、本線と副線の間にホーム（島式2面4線）。
- 松ノ浜・北助松: 上下線の外側にホームが向かい合う（相対式）。
- 堺: 内側2線の外側に副線2本があり、各副線と本線の間に島式ホーム（2面4線）。
- 羽衣: 上り線側に島式ホーム（本線と高師浜線の行止まり線が両側）、下り線側は外側の片面ホーム、南側に高師浜線が分岐。
- 浜寺公園: 下り線（図の上）は副線との間に島式ホーム、上り線（図の下）は本線の隣の副線の外側に片面ホーム。副線の分岐は両側とも駅の前後で本線へ戻る。
- 諏訪ノ森: 上下ホームの形のみ参考。図は「高架化工事中」の仮線で、上下ホームの位置関係は最新ではない。ユーザー指定の「踏切を挟んで離れた対面ホーム」を優先。
- 石津川: 相対式、ホームは上下で向かい合う。
- 湊: 上下線の間に島式ホーム1本。

注意: 図は石津川〜羽衣間が高架化工事中のため最新配線を反映していない。この区間の高架/地上は上の表（ユーザー指定）を優先し、図は線路・ホームの形の参考のみ。

## 平面形・勾配（地図の駅位置から読んだ概形）

地図画像の駅位置（泉大津(190,897) 〜 堺(738,60)）から駅間の方位を読んだ。泉大津〜高石は北東（約60°→50°）、高石〜羽衣で北北東（約30°）、羽衣〜浜寺公園でほぼ北（約16°）、以降は堺へ北北東〜北東（約21°→30°）。これをもとにした曲線: 松ノ浜〜北助松で左11°（R1700）、高石〜羽衣で左20°（R1430）、羽衣を出て左14°（R1300、高架を下りながら）、諏訪ノ森を出て右8°（R1200、上り坂）、湊〜堺で右5°（R1800）。石津川〜湊は直線。

- 羽衣を出てすぐ（5030m〜）−25‰で高架を下り、浜寺公園の地上へ。
- 諏訪ノ森を出て（7000m〜）カーブ兼+25‰の上り坂で高架へ上がり、上り切った所の石津川橋梁（7390〜7540m、鋼トラス150m）で石津川を渡り、約160m先が石津川駅のホーム。
- 駅間距離は営業キロ程表の値を優先。地図の縮尺は不明で、約10m/px 前後で概ね一致した（曲がりの向きと大きさの目安にとどめた）。

## 交差構造物・景観

- [泉大津市: 市内見どころマップ](https://www.city.izumiotsu.lg.jp/material/files/group/1/midokoromapura.pdf) は助松JCT・堺泉北有料道路・阪神高速湾岸線・南海線の地域配置を示す。松ノ浜〜北助松、北助松〜高石の道路横断はユーザー指定を採用。道路名、交差位置、幅は実測未確認のため架空名と概形で描画。
- [堺市・南海: 阪堺線対応の地元説明資料](https://www.city.sakai.lg.jp/shisei/toshi/rittaisuishin/honsen/zentainagare.files/setumeisiryou.pdf) の7〜8ページに南海・阪堺の交差部。浜寺公園〜諏訪ノ森間で路面電車線が南海の上を横断するモチーフに使用。資料の古い完成工程は現在の工事日程として使わない。
- [堺市: 連続立体交差事業の資料](https://www.city.sakai.lg.jp/shisei/gyosei/chogi/chogiyoshi_h29/chougigijiyoushi_290525.files/0525anken2.pdf) に石津川左岸の仮橋梁写真。ゲームの鉄橋は石津川付近を参考にした演出で、実物の支間長・鋼材断面・仮橋と本橋の構造を厳密に写していない。諏訪ノ森〜石津川間（石津川駅の手前）に配置する。
- 羽衣からの支線は高師浜線の高架線の描画だけ。運転コースには含めない。分岐曲率・描画延長はゲーム用。

- 羽衣の駅直結タワー: 泉大津寄りのホーム端の外側（上り線の右側、反転した下り線では左側で同じ物理位置）。約105m・28層の細長い箱形の塔身に、低層の商業棟（屋上庭園）、ホーム面と同じ高さの連絡通路、高架下の屋根付き歩廊を付けた概形。外壁は汎用の窓割りとバルコニーの水平線で、実在建物の名称・看板・ロゴ・寸法は写していない。夜は塔身・店舗の窓が点灯。実装は `world/coastal-tower.ts`（遠景: 塔身と素ブロックで約130三角形、近景: 店構え・屋上・通路で約2800三角形、650mで消す）。

描画位置（往路のs）: 道路1590m/2680m、路面電車跨線6310m、鉄橋中心7465m（区間7390〜7540m）、支線4980m、羽衣タワー中心4776m。
これらは該当駅間に置いた概形値。道路・路面電車のlengthは線路を横断する描画全長、鉄橋150m・支線900mも実測長ではない。
線形は上記の緩い曲線、地盤は平坦、高架面は9mで近似。実地形の標高データや地理座標をインポートしていない。
沿岸の背景も概形。西側の海は線路から900m以遠、工業地帯は約400〜650mに置く。実際の海岸線・施設の配置を写したものではない。
東側の低丘は2.6km以遠、約20〜65mの低い起伏で近似。空の稜線も東側だけに薄く低く描き、進行方向と海側を高い山で囲まない。復路では海・丘の左右を反転して地理的な側を維持する。

## 終着の速度照査

泉大津・堺は実際には本線の途中駅。ゲームの終着扱いを理由に車止めを置かない。
往復ともコース終着前に低速進入の連続速度照査を設ける。
これはゲーム用ATSの設定。実路線の保安装置の設置位置・照査速度・閉そく割りを再現したものではない。

## 再生成

`npm run timetable -- --shiokaze-only` で汐風線だけの時刻表を生成する。
普通・急行・特急、往路・復路それぞれで、勾配・分岐器制限・終着速度照査を含めて走行時間を計算する。
山岳線の時刻表はこのオプションでは変更しない。
