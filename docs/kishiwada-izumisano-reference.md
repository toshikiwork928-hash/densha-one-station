# 岸和田〜泉佐野 景観・駅舎の現状と資料

作成日 2026-10-09。難波〜岸和田で行った、実物に寄せる工程を、岸和田〜泉佐野にも当てるための資料。アプリのコードは変更していない。写真は閲覧だけで保存していない。寸法は不明で、外観は写真からの読み取り。
泉佐野駅は別紙 `izumisano-station-reference.md` を参照する。

## 1. 現状の穴

`docs/spec-kishiwada-izumisano.md` と現在のデータから確認できたもの。

- OSM データは取得日が 2026-10-08 で、川の外周（relation）を取る改良後のスクリプトで作られている。再取得は必須ではない。
- 手作りのランドマークがない。OSM の landmarks 43件は、小さな公園・神社・寺・住宅が中心。
- 駅舎の個別外観が未再現（5駅。泉佐野は概形で再現した。別紙）。
- 踏切11か所は、OSM の道路と線路の交点から選んだもの。2026-10-09 に OSM の踏切の点（railway=level_crossing）と照合し、結果は次のとおり。
  - 南海本線の10m以内にある踏切の点は18か所（同じ位置の重複を除く）。
  - 現行の11か所は、すべて OSM の踏切の点と対応する。位置の差は一律約70m。駅の座標を結んだ直線への射影で距離を概算した誤差で、位置のずれとは限らない。
  - 現行にない7か所は、概算の s で約1110、2590、2930、2990、4360、4510、5430。道路か歩行者用か、番号・名前（鶴原5号は約6120に対応）は未確認。
  - 現地写真との照合は未実施。
- 川の橋がない。`izumisano.ts` の `structures` は高架2区間だけ。OSM の水面が線路にかかる所が2か所ある。
  - s 約1700（蛸地蔵〜貝塚）。津田川。OSM の鉄道橋（bridge=yes）の長さは約31m。
  - s 約5090（二色浜〜鶴原）。見出川。OSM の鉄道橋の長さは約34〜36m。
  - 川の名前と橋の長さは、取得済みの OSM 生データ（`node_modules/.cache/osm/kishiwada-izumisano.raw.json`）で、鉄道橋と川の位置を突き合わせて確認した。橋の構造と高さは不明。
  - 貝塚〜二色浜は近木川。OSM では、線路が近木川の近くを約1.1〜2.3kmにわたり bridge=yes で描かれている（高架区間を含むと推定）。個別の橋モデルの対象にしない。構造は不明。
- 泉佐野の線路は3面5線だった。実駅の3面4線に直した（2026-10-09。別紙）。
- 高速道路（highways）は0件。範囲（線路の両側320m）内に取れなかっただけか、実在しないかは不明。

## 2. 駅の資料

配線は配線略図.net `figures/011_05.svg`。蛸地蔵・二色浜・鶴原・井原里は相対式2面2線、貝塚は2面4線（待避線あり）。現行コードの配線と合っている。

### 蛸地蔵

- 地上・相対式。東西に別の駅舎と別の改札があり、ホーム間の行き来はできない。改札は各ホームの和歌山市寄り。
- 上り（なんば方面）の西駅舎は、大正期の建物で、国の登録有形文化財（2022年登録）。
- 西駅舎の外観（写真）は、洋風の2階建て風。急勾配の灰色の屋根、薄い色の漆喰壁、アーチ窓、玄関の小さな庇。天窓にステンドグラス。
- 下りの東駅舎の外観は未確認で不明。

### 貝塚

- 地上・島式2面4線。橋上駅舎（1990年）。内側の2・3番が本線、外側の1・4番が待避線。
- 橋上駅舎は、東口が大きな鉄骨造で、白〜灰色、斜めの屋根面の目立つ外観。西口は白い小さな2階建て。
- 水間鉄道の貝塚駅（頭端式1面2線）が隣接する。ゲーム内での扱いは未定。
- 東は駅前のバスターミナル。西は寺内町と商店街、願泉寺（貝塚御坊）。
- 和歌山市寄りに上下の渡り線がある。定期列車は使わない。
- 上屋の形は不明。

### 二色浜

- 地上・相対式。駅舎はなんば寄りのホーム。
- 2025年12月20日に、両ホームをつないでいた構内踏切が廃止され、東駅舎が開業した。改札内でのホーム間の移動はできない。
- 旧駅舎は平屋、青い庇、白い壁、青い柱。新しい東駅舎の外観は不明。
- 現行ゲームの二色浜駅に構内踏切があるかは、未確認。
- 周辺は海水浴場と海浜公園。

### 鶴原

- 地上・相対式。駅舎はなんば寄り。当初は上りホーム側だけが改札で、下りホーム側にも後から増設された。
- 両ホームは地下道で結ばれている。構内踏切の記載はない。
- 外観は小さな平屋。上り側は切妻の屋根、白い壁、地蔵尊の像。下り側は灰色の壁で、屋根は切妻。
- 周辺は住宅が中心。近くに見出川。

### 井原里

- 地上・相対式。駅舎はなんば寄りのホームにあり、2020年に和歌山市側にも駅舎ができた。
- 構内踏切でホーム間をつなぐ（Wikipedia）。別の資料に地下道の記述もあり、食い違うため不明。
- 外観は平屋の簡素な駅舎。灰色と白の壁、切妻の屋根。
- 周辺は、北側に府道20号の下をくぐる通路、西側に大型商業施設。

### 岸和田（既存コースと同じ描画）

- 屋内駅の描画を使う。変更しない。

## 3. 実物に寄せる作業の一覧

### ローカルでやること

1. 蛸地蔵の東駅舎、貝塚の屋根、二色浜の新東駅舎、鶴原・井原里のホーム上屋の写真を追加で見る。最新のものを優先する。
2. 川2か所の橋の形（構造・高さ）を、地図と写真で確認する。名前と長さは確認済み（1章）。
3. 踏切のうち、現行にない7か所を入れるか決める。11か所を現地写真と照合する。
4. 貝塚の水間鉄道の隣接部と、泉佐野の東西の駅前を、ゲームに入れるかを決める。

### クラウドでやること（資料が揃ってから）

1. 駅ごとの駅舎・上屋を、`station-architecture-reference.md` と同じ形式で定義する。
2. 川2か所の橋を `structures` に追加する。
3. 踏切の位置を直す。
4. 泉佐野を3面4線に変える（別紙）。実施済み（2026-10-09）。

### 画面確認（ローカル）

素材を読み込める dev サーバーで、各駅と区間を上り・下りの両方向で見る。`?inspect=1&route=izumisano` と `?inspect=1&route=izumisano-up` が使える。`__osmWhy` で、建物が置かれない理由を確認する。
