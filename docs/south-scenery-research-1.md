# 南海本線 泉佐野〜みさき公園 景観調査メモ 1

調査日は 2026-10-09。コードは変更していない。

## 読み方

- 進行方向は泉佐野→みさき公園（南西へ走る）。右は西〜北西（海側）、左は東〜南東（山側）。
- 「OSM由来」と書いた数値は、OpenStreetMap（Overpass API）の座標から私が手計算した。誤差は数十m見ておく。OSMは地理院データではない。
- 写真（Wikimedia Commons など）は読んでいない。写真から分かる形（屋根の形、色、高さ）はすべて不明。
- 橋や高架の高さ、長さ、建物の形は、どの資料にも数値がなかった。不明と書く。
- 配線略図.net の図（SVG）は、座標から線の位置関係だけ読んだ。

## 1. 泉佐野駅の南側（空港線の分岐、JR関西空港線との交差）

### 確認できたこと

駅の構造
- 泉佐野駅は島式3面4線の高架駅。南海本線と空港線がホームを方向別に共用する。
- 4番と3番のりばで、関西空港方面と和歌山市方面の対面乗換ができる。
- 当初は4面5線の計画だったが、山側ホームが削除されて3面4線になった。
- 空港線の起点。1番のりば付近の向かいに0キロポストがある。
- 難波から34.0km。羽倉崎駅から2.1km。
- 和歌山市・関西空港方面に、上り線から下り線へ入る渡り線がある。
- 2番と3番、4番と5番のホームは、それぞれ線路を共有する。

分岐のようす（Wikipedia の沿線概況）
- 泉佐野を出てしばらくは、空港線と本線が線路を共用する。
- 左へカーブしたあと、空港線が右へ分かれる。
- 空港線の下り線は、本線の高架を乗り越える「高々架」になる。
- 空港線の上下線は一度近づき、また離れる。
- 本線は、JR関西空港線と関西空港自動車道の高々架の下をくぐる。国道481号とも交差し、その後で地上に下りる。国道481号が立体か平面かは、資料の読み取りが食い違うので不明。

分岐位置（OSM由来）
- 泉佐野駅の中心は北緯34.4112、東経135.3170。
- 分岐する点は北緯34.4103〜34.4105、東経135.3143〜135.3149あたり。
- ホームの南西端から約100〜150m、駅中心から約260m南西。
- 分岐後、本線は南西へ向かう。空港線は最初は本線と並び、東経135.3100付近から西寄りに曲がり、北西のりんくうタウンへ向かう。
- 空港線は2段重ねの高架（OSMの layer が2と3）。本線は layer 1。

本線が地上に下りる位置（OSM由来）
- 北緯34.4014、東経135.3024。駅中心から約1.7km南西。
- 大阪府の資料では、高架化は泉佐野市湊1丁目から東羽倉崎町までの2.8km、踏切9か所を除却。1.1km区間は1995年3月、1.7km区間は上り線が2002年5月に高架へ切替え。

JR関西空港線が本線をまたぐ位置（OSM由来）
- 北緯34.4052、東経135.3072あたり。
- 泉佐野駅の中心から約1.1km南西。分岐点からは約0.9km。
- JRが上、南海本線が下。JRはOSMで layer 3（橋）、南海本線は layer 1（橋）。
- 向き。JRは南東から北西へ走る（方位およそ311度）。南海本線は南西から北東（およそ46度）。ほぼ直角に交差する。
- JR関西空港線の記述（Wikipedia）では、JRは日根野を出て右カーブし、阪和線の上り線をまたぎ、池を越え、旧佐野陸軍飛行場跡を通る。南海本線の約300m手前から国道26号をまたいで上り、南海本線の高架の上を通る。
- JRのあと、りんくうタウン側ではJRが南海空港線の上り線と下り線の間を通り、旧海岸線を越えて埋立地へ入る。

りんくうタウンとの位置関係
- りんくうタウン駅（OSM）は北緯34.4108、東経135.2997。泉佐野駅の約1.6km西。ほぼ真西。
- 空港線の営業キロは泉佐野〜りんくうタウンが1.9km。
- りんくうタウン駅は島式1面4線。内側2線がJR、外側2線が南海。
- 駅を出ると両社の線路が合流し、関西国際空港連絡橋（全長3,750m、2層構造で鉄道が道路の下）に入る。
- 空港線の手前では、関西空港自動車道、国道481号、JR線が左後方から近づいて並走する（Wikipedia）。

### 不明

- JRの橋の長さ、高さ。南海の線路面からの高さ。
- 空港線の2段高架それぞれの高さ。
- 分岐ポイントの正確な位置（メートル単位）。
- 橋や橋脚の形、色、材質。写真を読んでいない。

## 2. 羽倉崎検車区

### 確認できたこと

位置
- 羽倉崎駅に隣接する。南海本線の車両基地で、住ノ江検車区の支区として扱われていた（2005年再編）。2020年10月に「羽倉崎検車」に改組、2021年10月に検車区が統合された。
- 車庫は進行方向（泉佐野→和歌山市）の左側（Wikipedia 南海本線）。
- OSM由来で、東〜南東（山側）。羽倉崎駅のホームの樽井寄り（南西側）に沿って延びる。
- 羽倉崎駅の座標は北緯34.3994、東経135.2998。

規模（OSM由来）
- 構内線路（service=yard）の北東端は北緯34.3990、東経135.2994、南西端は北緯34.3940、東経135.2938。長さは約760m。
- 南西端で並んだ線が約14本。OSMに描かれた留置線の目安は10本台前半。本数は図からの数えなので、実際とずれる可能性がある。
- 北東側は、駅の泉佐野寄り約230m先で本線に合流する引上げ線が見える（OSMの siding）。

本線との接続
- 羽倉崎駅は2面3線。1・2番線が島式、3番線が単式。駅舎は3番線側にある。
- 1番線は車庫に直接つながる。難波方面への出入庫は主に1番線。
- 2・3番線も渡り線で車庫とつながる。難波方面からの入庫の一部は2番線、和歌山市方面からの入庫はすべて3番線。
- 難波方面への折返しは1番線。
- 1・2番線は区間急行の出入庫のため8両編成に対応。

周囲のようす
- 進行方向の右側は、旧阪本紡績工場の跡地に建つ高層マンション群と商業地。ホームセンター、スーパーなどが進出。
- 駅前に銀行。線路の北側と南側にコンビニがある。
- 泉佐野〜羽倉崎の間で、本線はJR関西空港線と関西空港自動車道の高架の下をくぐり、国道481号と交差して、地上に下りる。
- 羽倉崎駅から先は、列車本数がラッシュ時中心で減る。

### 不明

- 留置線の公式な本数。
- 車庫の建物（検修庫、洗浄線の屋根）の形、色、高さ。
- 構内の線路が何番線までか。
- 車庫が平面で、本線より高いか低いか。

## 3. 線路が海の近くを走る区間

### 確認できたこと

海の向き
- 海は進行方向の右側（北〜西）。確認できた。OSMの海岸線は、尾崎〜みさき公園のすべてで線路の北西〜北にある。

区間ごとの流れ（Wikipedia の概況 ＋ OSM由来の距離）
- 泉佐野〜羽倉崎〜井原里〜樽井。海は埋め立てられ、りんくうタウンができた。車窓に海はない。
- 樽井付近。かつては右の窓から大阪湾を間近に見られたが、埋立てで、いまはイオンモールりんくう泉南などの商業施設や工場が見える。
- 岡田浦〜尾崎手前。右手前方に関西空港と連絡橋が遠くに見え始める（Wikipedia）。線路と海岸線の距離は約1.2km（尾崎の約1km手前、北緯34.3661、東経135.2503の座標で計算）。
- 尾崎駅。海岸線は西に約480m。
- 尾崎〜鳥取ノ荘。約430〜500m。
- 鳥取ノ荘駅（北緯34.3513、東経135.2317）の少し先から。海岸線に最も近づく。北緯34.3500、東経135.2276あたりから北緯34.3435、東経135.2167あたりまでの約1.2kmで、海岸線との距離がおよそ50〜160m。いちばん近いのは東経135.2243付近の約55m、東経135.2197付近の約65m、北緯34.3435付近の約60m。
- 箱作駅（北緯34.3414、東経135.2128）。海岸線は北に約270m。箱作の人工ビーチ（ぴちぴちビーチ）側。駅から徒歩約15分の人工海水浴場（大阪観光局の紹介）。
- 箱作〜淡輪。線路は西南西へ走る。東経135.2047付近で海岸線まで約110〜140m。東経135.2020〜135.1950で約230〜300m。淡輪付近（東経135.187〜135.178）で約450〜590m。
- 淡輪〜みさき公園手前。約600〜800m。みさき公園駅の手前で線路は海岸から離れ、内陸の岬町へ入る。
- みさき公園駅。海岸線は北に約750m。駅の北〜北西に長松自然海浜がある（Wikipedia）。
- Wikipedia（南海本線）の記述。鳥取ノ荘を過ぎると海岸が右に近づく。箱作で人工ビーチ、せんなん里海公園のそばを通って岬町へ入る。みさき公園の手前で、大阪湾の海岸が右前方にまた現れ、長松自然海浜が見える。

海側の地物
- 海水浴場、人工ビーチ。箱作（ぴちぴちビーチ）と淡輪（ときめきビーチ、夕日の眺めで知られる）。
- 尾崎駅の西口から徒歩約10分の民宿の案内に夕日の記述。
- 淡輪付近のOSM海岸線に、海上の小さな閉じた島状の線が2か所（北緯34.3388、東経135.1935付近と、北緯34.3365、東経135.1820付近）。防波堤か離岸堤かは不明。
- 公園。せんなん里海公園、長松自然海浜。
- 工場。多奈川側に川崎重工の造船所の歴史がある（多奈川線の項）。

### 不明

- 防波堤、堤防、テトラポッドの有無と位置。
- 線路と海の間にある建物、防風林、道路。
- 車窓から海が実際に見える範囲。OSMの海岸線までの距離は出せたが、視界は不明。
- 樽井〜岡田浦間の海岸線座標。Overpass が応答せず、取得できなかった。

## 4. みさき公園駅と多奈川線

### 確認できたこと

駅の構造
- 盛土上の島式2面5線の地上駅。
- 1・2番線が一つの島式ホーム、3・5番線がもう一つの島式ホーム。4番線は3番線の和歌山市寄りを切り欠いた線。
- 1・2番線が南海本線の下り（和歌山市方面）、3番線が上り（なんば方面）、5番線が多奈川線。
- 4番線はもとは多奈川方面用で、2024年5月時点で未使用。2005年までは初発列車だけが使った。2023年のダイヤ改正以降、多奈川線の全列車が5番線を発着する。
- 1・2番線から多奈川方面へ、5番線からなんば方面へ発車することもできる。
- 改札はみさき公園側と南側の道路側（東出口）の2か所。各ホームと駅舎は地下道でつながる。
- 昔は難波側に構内踏切があった。
- 府道752号が駅の下を通る。

位置関係（OSM由来）
- 駅の座標は北緯34.3242、東経135.1612。
- 1・2番線のホームが東（山）側、3・4・5番線のホームが西（海）側。5番線は西側の島の外側の線。
- 5番線に当たる多奈川線の線路は、ホームの北東端でも南西端でも本線とつながる（OSMの渡り線。なんば方面への直通可）。

多奈川線の分岐
- 分岐は駅の南西（和歌山市寄り、進行方向の先）。渡り線がある位置は北緯34.3225〜34.3228、東経135.1588〜135.1592。駅中心から約250m。
- 多奈川線は本線の右側（西・海側）を並んで出ていく。しばらく並んだあと、本線が左（南南東）へ曲がるのに対して、多奈川線は右（西）へ大きく曲がって離れる（Wikipedia）。
- 離れ始めるのは北緯34.3218、東経135.1578あたり。北緯34.3190では、多奈川線が本線の約90m西。その先は西南西〜西へ向かう。
- 配線略図の図（SVG）でも、分岐は本線の下側（図の座標上）で、孝子方（和歌山市方）寄り。これは図の向きの問題で、東西南北との対応は OSM を優先した。

多奈川線
- 営業キロ2.6km、単線、直流1500V、軌間1067mm、自動閉塞。最高速度は資料により50km/h と45km/h と食い違う。
- 駅はみさき公園（0.0km）、深日町（1.4km）、深日港（2.1km）、多奈川（2.6km）の4駅。みさき公園以外は無人。線内に行き違い設備はない。
- 全列車が線内折返しの普通で、2両のワンマン。
- 多奈川駅は地上の2面1線（使うのは1ホームだけ）。以前は2線で、いま使う線が旧2番線。車止めは駅舎のある西端。夜間留置はない。駅舎は西端、トイレあり。北側に工場、南側は府道65号を挟んで住宅、西に岬町文化センター。大阪府内でいちばん西の駅。
- 深日港駅は、淡路島への航路と連絡していた。航路は1998年の明石海峡大橋の開通後に衰退し、のちに廃止。
- 配線略図の図でも、終点に車止めの記号が1つある。

多奈川線の車両
- 2両のワンマン車。Wikipedia の記述では 2200系と2000系とともに、7100系のワンマン対応2両編成（7167F、7187Fなど）が使われる。
- 2200系は多奈川線で運用された（過去形の記述）。2200系2編成が引退する報道があるが、検索結果の要約には年が書かれていない。
- 6000系が多奈川線に入るという記述は確認できなかった。6000系の記事は、難波〜橋本間と泉北線で使うと書いている。つまり指示にあった6000系は、現在は多奈川線では確認できない。

みさき公園駅の周囲
- 北側に、南海グループが運営した遊園地「みさき公園」のメインゲート。2020年3月31日に運営から撤退して休園。園内の建物と施設は岬町に譲渡され、2021年から「岬町立みさき公園」。
- 西側に大阪ゴルフクラブのクラブハウス。
- 駅前（みさき公園側）に舗装された広場。バスは岬町コミュニティバスなど。
- 東出口の外は府道752号と住宅地。
- 周辺に岬郵便局、西陵古墳、白峠山古墳、真鍋山古墳、府立岬高校、岬中学校、長松自然海浜。

### 不明

- 5番線のホームの長さ（何両分か）。
- 多奈川線の車止めの形（コンクリートか鉄製か）。
- 多奈川線の線路が海岸に近いか。座標を取得できたのは、みさき公園から約0.9kmまで（北緯34.3186、東経135.1518付近まで）。
- 駅舎や遊園地跡の建物の形、色。
- 2025年以降に多奈川線へ入る車両の実際の組み合わせ。

## ゲームに取り込むときの注意

- 泉佐野駅の南側は、本線が高架のまま南西へ約1.7km進んで地上に下りる。空港線は分岐後、右（西・北西）へ離れていく。分岐点は駅中心の約260m先。
- JR関西空港線は、泉佐野駅の約1.1km先で南海本線の真上を、ほぼ直角に（南東から北西へ）またぐ。ゲームで橋を置くなら、この位置に1本。高さと長さは資料にないので、遠景として決めてよい。
- 羽倉崎検車区は線路の左側（東〜南東）。羽倉崎駅の樽井寄りに約760mの長さで並ぶ。右側は高層マンションと商業地。
- 海は進行方向の右側。いちばん近いのは鳥取ノ荘の先の約1.2kmの区間（約50〜160m）。尾崎〜鳥取ノ荘は約430〜500m。箱作〜淡輪は約110〜600m。みさき公園の手前で海岸から離れる。
- みさき公園駅の多奈川線は、駅の南西側（前方）で本線の右へ分かれる。5番線は島式ホームの外側（西）。多奈川線は単線で、終点に車止め。
- 多奈川線の車両は、2両の7100系や2000系のワンマン車。6000系は確認できなかった。
- OSM由来の数値は私の手計算で、地理院地図や現地では確認していない。景観の細部（建物の色、橋の高さ）は資料に写真がなく不明のまま。
