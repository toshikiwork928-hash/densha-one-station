# 南海 和歌山市付近の景観調査 その2

調査日は2026-10-09。対象はみさき公園〜和歌山港のうち、和歌山市付近。
調べ方は WebSearch と WebFetch のみ。写真や配線図の画像は読めていない。画像でしか載っていない情報は「不明」とした。
ページ内容は要約ツール経由で取得している。数値は出典に書かれていたものだけを載せた。推測は「推測」と明記した。

## 1. 紀ノ川橋梁（南海本線）

### 確認できたこと

位置
- 紀ノ川駅と和歌山市駅の間で紀の川を渡る。和歌山大学前駅と紀ノ川駅の間ではない。
- 駅の並びは和歌山大学前、紀ノ川、和歌山市。
- 紀ノ川駅は川の北側（右岸側）にある。1903年以前の仮終着駅だった和歌山北口駅は北岸にあった。和歌山市駅は南側。
- Wikipedia の南海本線の路線図では、紀ノ川駅が62.5km、和歌山市駅が64.2km。橋は両駅の間にある。

上り線と下り線は別々の橋
- 単線の橋が2本、並んで架かっている。
- 上り線は1903年（明治36年）竣工。下流側にある。
- 下り線は1922年（大正11年）竣工。土木学会の記載は大正11年。大正12年とする記事もある。
- 上り線はアメリカン・ブリッジ社の製造。下り線は国産で、設計は鉄道院とされる。
- 2022年に土木学会の選奨土木遺産に認定。

橋の長さと形式
- 上り線の橋長は627.4m（和歌山県議会の質問でも約627m）。
- 下り線の橋長は628.8m。
- 上り線の構成は、右岸（北）側から次の順。
  - 70ft（約22.1m）の上路鋼板桁橋が16連。
  - 200ft（約62.1m）の下路曲弦プラットトラス橋が3連。
  - 70ftの上路鋼板桁橋が3連。
- 下り線の構成は、右岸（北）側から次の順。
  - 上路鋼板桁橋が16連（約22.3m）。
  - 下路曲弦ワーレントラス橋が3連（約62.4m）。
  - 上路鋼板桁橋が3連（約22.3m）。
- つまり、トラスは川の南寄りの中央から南側にある。北側は長い桁橋の区間。
- 上り線のトラスは、格点がピン結合で、下弦材がアイバー（板状の鋼材）。赤く塗られている。
- 下り線のトラスは、格点がガセットプレートとリベット接合。上り線と形が違う。
- 上り線と下り線でスパンはわずかに違う。

橋脚
- 橋脚は上り線と下り線それぞれ、22径間なので21本（推測。出典に本数の記載はない）。
- 明治期の橋脚は煉瓦積みが目立つ。いくつかはコンクリートに置き換えられている。
- 2016年12月〜2017年5月に、高水敷部分の上下線20橋脚を鋼棒挿入で補強した（県議会の答弁）。

並行する橋と周辺
- 国道26号の紀の国大橋が、南海橋梁の東側（上流側）に架かる。
- 旧加太線の鉄道橋だった河西橋は、現在の南海橋梁より約700m下流にあった。戦後に鉄道橋としては廃止。道路・人道橋として使われ、架け替えで全長473m、幅6.8mになり、2025年8月17日開通予定と報じられていた。
- 南海橋梁の先（下流側）に北島橋が見えるという撮影記事がある。
- 紀の川の下流の感潮区間（海水が上がる区間）は川幅が約500m以上。
- 橋の南側の踏切から和歌山城が見えるという撮影記事がある。
- 1998年に耐震性を理由に架け替えが検討されたが、調査で支障がないとして中止。
- 平日の運行は118便、休日103便（県議会での議員の発言。県が確認した数字ではない）。

### 不明
- 水面から橋桁までの高さ。
- 橋脚の間隔の実測値（トラス部は約62m、桁部は約22mということだけ分かる）。
- 上り線と下り線の線路中心間隔。
- 歩道の有無。確認できなかった。
- JR紀勢本線が南海の橋と並行しているかどうか。確認できなかった。JR阪和線の紀ノ川橋梁は別の場所（上流側）にある。南海橋梁と並ぶ鉄道橋は見つからなかった。
- 橋脚のうち、煉瓦とコンクリートの内訳。

## 2. 加太線の分岐

### 確認できたこと
- 分岐する駅は紀ノ川駅。
- 紀ノ川駅は相対式2面2線の地上駅。南海本線と加太線は、進行方向ごとにホームを共有している。
- 分岐は、ホームの難波寄り（北東側）にある平面分岐。本線と平面で分かれる。
- 加太線は紀ノ川駅から西へ向かい、紀の川の北岸沿いを加太へ進む。
- 紀ノ川駅の次は梶取信号所、次が東松江駅。
- 加太線は全線単線。ただし、本線と合流する紀ノ川駅付近に短い複線区間がある。
- 営業キロは9.6km。1500V直流。最高速度は80km/h。
- 加太線の全列車が和歌山市駅へ直通する。紀ノ川〜和歌山市は南海本線を走り、紀ノ川橋梁を渡る。
- 和歌山市駅の加太線ホームは3番線。
- 車両は7100系が中心で、2000系も使う。ワンマン運転。
- 「めでたいでんしゃ」は7100系を使う。2024年から2000系ベースの「かなた」も走る。
- 編成は2両の可能性が高い（2019年に2編成をつないで4両にした例がある。出典に2両と直接は書かれていない。推測）。
- 加太線の旧線は、和歌山口（のち北島）から旧・河西橋を渡って和歌山市駅に入っていた。1950年から松江線（現・本線）経由の紀ノ川回りに切り替わった。

### 不明
- 分岐部の分岐器の数、渡り線の有無などの詳しい配線。
- 加太線が本線の下り線側・上り線側のどちらから分かれるか。
- 加太線の車両の正確な編成表記（公式の2両表記は未確認）。

## 3. 和歌山市駅（南海）

### 確認できたこと

構造と番線
- 南海は地上駅。2面5線。JR西日本の部分は1面1線。
- 駅ビルは南海和歌山ビル。改札は1階。2017年に2階から1階へ移した。高架駅ではない。
- 3番線は加太線。行き止まりの頭端ホーム。
- 4・5番線は南海本線のなんば方面と、和歌山港線の特急サザン・急行。4・5番線だけが和歌山港方面へ通じる。
- 6番線は南海本線のなんば方面。
- 7番線は和歌山港線の和歌山港行き。2014年10月から普通列車専用ホーム。
- 6・7番線は同じホームを中ほどで分けた形。向かい合わせで、線路終端標識と砂利・枕木の車止めがある。線路と架線はつながっている。
- 5・6・7番線は跨線橋で結ばれている。
- 2012年度のエレベーター設置で3番線の有効長が短くなり、加太線の専用ホームが6番線から3番線に変わった。
- 3番線は行き止まり。

検車区
- 住ノ江検車区和歌山出張場（2009年から。2020年10月に和歌山検車へ改組）。
- 和歌山市駅に隣接している。
- 6番線の北側が車庫で、留置車両が見える。7番線の北側にも留置線がある。
- 加太線・多奈川線のワンマン対応の7100系は、和歌山検車の管轄。
- 車庫付近に、かつて加太線の和歌山口駅があった。

JRとの位置関係
- JR紀勢本線の駅は同じ構内。和歌山駅から3.3km。
- 6番線の東側で南海とJRが並走し、その後JRは右へ折れて和歌山方面へ向かう。
- 南海線とJR線の間に、非電化の渡り線がある。旅客列車は走らず、車両の搬入などに使う。
- 加太線は紀ノ川駅経由で、駅の東側から入る。
- JR側の1番線とその機回し線は1992年に撤去。駐車場になった。

和歌山港線への線路の出方
- 4・5・7番線の線路が和歌山港線につながる。
- 駅を出ると、検車区に並ぶ車両の横を通り、線路が1本に集まって単線になる。紀の川の河口沿いを進む。
- 駅から約0.8kmの県社分界点（旧・久保町駅）まで南海の線路。その先は和歌山県の線路。

### 不明
- 検車区の留置線の本数と、敷地の広さ。本数の記載はない。古い配線図には30番台の番号の留置線があるという推測コメントがあるだけ。

## 4. 和歌山港線（和歌山市〜和歌山港）

### 確認できたこと
- 全線単線。複線区間なし。営業キロ2.8km。1500V直流。両端の駅で行き違いができる。
- 駅は和歌山市と和歌山港のみ。久保町・築地橋・築港町の3駅は2005年11月27日に廃止。
- 県社分界点（旧・久保町、0.8km付近）より先の2.0kmは和歌山県の線路で、南海が借りて運行。
- 路線図には川の横断が2か所ある。市堀川（和歌山市駅の近く）と築地川（県社分界点と築地橋駅の間）。橋かどうか、長さは書かれていない。
- 別の紹介記事では、水路を2か所渡る（久保町の後と築港町の後）と書かれている。名前と長さの記載はない。
- 同記事は、紀ノ川河口沿いを進み、砂州を渡って、終点手前で左に曲がる、とも書いている。
- 和歌山港駅は島式1面2線の盛土駅（築堤上）。改札とコンコースは2階、ホームは3階。有効長は8両。
- 2002年5月26日まで、和歌山港駅の先に水軒駅へ線路が続いていた。今は車止めがあり、先の線路は撤去されている。
- 水軒方面の廃線跡に、花王工場の出入口をまたぐ高架橋が残っていた。
- 和歌山港駅の周りは、海沿いに工場や倉庫が並ぶ。
- 紀の川河口大橋（道路橋、橋長521.3m）は駅から離れていて、鉄道の橋ではない。

### 不明
- OSM にある和歌山港手前の約220mの橋が何か。確認できなかった。
  - 市堀川と築地川の橋は、長さが出典にない。
  - 「築港町を出てから高架になって和歌山港に着く」という記述が検索結果の要約にあったが、元ページで直接確認できていない。
  - 和歌山港駅は「盛土駅」とする記述と、手前が高架とする記述があり、食い違う。
  - 推測として、220mの橋は築港町〜和歌山港間の高架橋か、水路をまたぐ橋の可能性がある。断定できない。
- 築堤が続く範囲。
- 橋の高さと橋脚の数。

## ゲームに取り込むときの注意

- 紀ノ川橋梁は、上り線と下り線が別々の単線橋。約628mある。北側（紀ノ川駅側）に桁橋が約16連で約350m、その先にトラス3連が約190m、最後に桁橋3連。トラスは赤い曲弦トラス。
- 上り線のトラスはプラット型、下り線はワーレン型で、形が違う。上り線が下流（西）側、下り線が上流（東）側。
- 橋脚は各線21本ほど（推測）。明治側は煉瓦。水面からの高さは不明なので、見た目で決める。
- 紀ノ川駅と和歌山市駅の間で川を渡る。和歌山大学前〜紀ノ川間ではない。
- 紀ノ川駅の難波寄り（北東側）で加太線が平面で分かれる。加太線は西へ向かう単線。本線と一部で複線区間を共有する。
- 加太線は全列車が和歌山市駅へ直通する。紀ノ川橋梁も本線側を走る。
- 和歌山市駅は地上駅。3番線が加太線、4・5番線が本線と和歌山港線、6番線が本線、7番線が和歌山港線。6・7番線は同じホームを分けた形で、間に車止めがある。
- 検車区は駅に隣接し、6番線と7番線の北側にある。留置線の本数は不明なので、数本程度としてぼかす。
- 和歌山港線は単線で、紀の川河口沿いの低地を通る。途中の3駅はすでに廃止なので、駅は作らない。
- 和歌山港駅は盛土の上に高いホームを持つ。手前の約220mの橋の正体は不明。配置は OSM に合わせ、名前や形は断定しない。
- 並行する紀の国大橋（国道26号）は東側（上流側）。河西橋は約700m下流に別にある。JR紀勢本線の鉄橋は並行していない。
