# 南海空港線

トップページで「南海空港線」を選ぶと、岸和田発の通しコース（16.8 km）と泉佐野発のコース（8.8 km）を選べます。この2コースは下りの関西空港行きです。上りは「関西空港 → なんば」を選ぶと、空港急行または特急ラピートβで、泉佐野から本線に入り、なんばまで通して運転できます。泉佐野からりんくうタウンまでは1.9 km、そこから関西空港までは6.9 kmです。[南海電鉄の鉄道事業資料](https://www.nankai.co.jp/lib/company/handbook/pdf/handbook2025_03.pdf)

## 停車駅と時刻

| 種別 | 岸和田から泉佐野まで | 泉佐野から関西空港まで |
|---|---|---|
| 普通 | 各駅に停車 | 各駅に停車 |
| 空港急行 | 岸和田・貝塚・泉佐野に停車 | 各駅に停車 |
| 特急ラピートβ | 岸和田・泉佐野に停車 | 各駅に停車 |

なんば行きの通しコースは42.8 kmです。ラピートβは関西空港、りんくうタウン、泉佐野、岸和田、堺、天下茶屋、新今宮、なんばの順に停車します。空港急行はさらに貝塚、春木、泉大津、羽衣にも停車します。終着駅のATS制動は下りでは関西空港、上りではなんばで働きます。[南海電鉄のりんくうタウン駅上り時刻表](https://www.nankai.co.jp/traffic/jikoku/pdf/rinkutown/a_02.pdf)

ゲーム用のダイヤには、各コースの線形、制限速度、車両性能と終着時の減速を反映しています。アプリのディレクトリで `npm run timetable -- --airport-only` を実行すると、上下3コースの時刻表を再生成できます。

## 駅と景観

| 駅 | ゲームでの表現 |
|---|---|
| [泉佐野](https://www.nankai.co.jp/traffic/station/izumisano.html) | 本線と共通の島式3面4線です。自列車は外側の1番線を出て、空港方面へ右に曲がります。 |
| [りんくうタウン](https://eki.jr-odekake.net/premises?id=0622601) | 3階の島式ホーム2面を南海とJRが共有します。外側の1・4番線は南海、内側の2・3番線はJRです。両ホームから階段で下りた2階に改札と駅前へ続く通路を置きました。 |
| [関西空港](https://www.jr-odekake.net/station/img/premises/0622602.pdf) | 列車は掘割を下り、人工地盤の下にある1階ホームに入ります。南海とJRが島式ホームを1面ずつ使います。各ホームから2階に上がると、改札階の通路が第1ターミナルとエアロプラザを結びます。 |

岸和田から泉佐野までの駅と街並みは既存の本線コースと共通です。空港連絡橋では道路の下を列車が走ります。空港線の曲線、勾配、ホーム寸法、分岐位置、橋やターミナルの形はゲーム用の近似です。JRは線路とホームを再現しています。

## ATSと採点

下りは関西空港、上りはなんばの停止位置まで残り1,500 mで進入を予告し、残り1,000 mから速度を照査します。速度超過が3 km/hを超えると、非常制動が作動します。途中駅では速度超過と停止信号の冒進を採点に反映します。

りんくうタウン駅には、両ホームの中央約165 mに帯状の上屋を置きました。中央2線の上では白い横梁とアーチの間から空が見えます。外側線の脇に透明の防風板を設け、ホームの階段口から2階へ下りる構造にしました。[りんくうタウン駅の現地写真とホームの記録（2021年）](https://ameblo.jp/s-limited-express/entry-12706532868.html)

関西空港駅では、2・3番線の間に角柱を並べました。ホーム上は浅い曲面天井と帯照明で覆い、側壁上部の採光窓から昼光が入ります。床のタイル、オレンジ色のベンチ、番線表示は参考写真に合わせています。

### 分岐、海上橋、駅前施設

泉佐野を出た空港線の下り線は、上下別の高架で本線の架線を越えます。分岐の下を通る本線には「泉佐野〜みさき公園」コースの線形と勾配を使います。りんくうタウンに入るJR線は、駅の内側2線から内陸へ続きます。JRの取付線形と高架の寸法はゲーム用の近似です。

空港連絡橋は約3.75 kmです。中央部は道路と鉄道が上下に重なる鋼トラス、両岸では道路が鉄道の脇に開く構造として描いています。ゲーム内では海上の橋脚間隔とトラスの部材を簡略化しています。[土木学会関西支部の橋梁資料](https://www.jsce-kansai.net/wp-content/uploads/2019/07/koukyou0726-3.pdf)

りんくうタウン駅の空港方面左手には、シークルの商業棟と高さ85 mの大観覧車「りんくうの星」が見えます。右手にはゲートタワーが立ちます。海岸に近いりんくう公園では、緑地と潮が出入りする内海の輪郭を地図から写しました。[大阪府のりんくう公園案内](https://www.pref.osaka.lg.jp/o130340/kishido/kishido-home/rinkuu.html)・[シークルの大観覧車案内](https://www.seacle.jp/floor/shop/15.html)・[観覧車の地図](https://www.openstreetmap.org/way/397462507)・[内海の地図](https://www.openstreetmap.org/way/585049445)

連絡橋の空港島寄りでは、第1滑走路の北東端で離着陸する旅客機が見えます。滑走路の位置は、OpenStreetMapの南海関西空港駅と滑走路端の位置関係をもとに、ゲームの空港島に合わせました。離着陸の順番・時刻・飛行経路はゲーム用です。[第1滑走路の地図](https://www.openstreetmap.org/way/40983116)・[関西国際空港の展望案内](https://www.kansai-airport.or.jp/shop-and-dine/skyview/view)

空港線の沿線データは、OpenStreetMapの建物386件、地上道路679本、駐車場や緑地などの面83件を収録しています。描画時は線路や駅前施設と重なるものを除きます。海上の水面は連絡橋の両岸を基準にした近似です。通しコースは泉佐野で本線と空港線のデータをつなぎます。[OpenStreetMapの出典とライセンス](https://www.openstreetmap.org/copyright)

### 空港島の外形

第1期島の埋立地は、駅と滑走路に沿った海岸線を地図から写し、外周に護岸を設けました。北東端の護岸はゲームの連絡橋の位置に合わせています。空港島へ渡ると線路は高架を下り、関西空港駅の手前で掘割に入ります。高架が終わる位置と護岸の高さはゲーム用の近似です。[第1期島の海岸線](https://www.openstreetmap.org/way/131098515)

関西空港駅へ向かう列車は、島内道路の下をくぐり、一度空が見える掘割を通って、人工地盤下のホームに入ります。道路をくぐる区間と駅の入口は地図の線路データに合わせました。勾配、擁壁の高さ、梁や照明の間隔はゲーム用の近似です。[島内道路の設計資料](https://archiveservier-airportreview-s3.s3-ap-northeast-1.amazonaws.com/target/target4/1994%E5%B9%B490%E5%8F%B7/1994%E5%B9%B4_090%E5%8F%B7_%E3%80%8C%E5%B3%B6%E5%86%85%E9%81%93%E8%B7%AF%E3%80%8D.pdf)・[道路の下を通る線路](https://www.openstreetmap.org/way/394999728)・[駅の屋内を通る線路](https://www.openstreetmap.org/way/394999741)

### 景観の確認方法

`npm run verify:road-collision` は、りんくうタウン駅周辺の建物外形と道路幅の重なりを3コースの座標で検査します。連絡橋の取付道路についても、描画と同じ中心線と幅を使います。

開発サーバーで `?inspect=1&route=airport` を開き、「運転台」を選ぶと、同じ場所を繰り返し確認できます。通しコースは `?inspect=1&route=airport-through` で開きます。位置欄はコースの座標をメートルで指定します。

| 確認する景観 | 泉佐野発 | 岸和田発 |
|---|---:|---:|
| 泉佐野分岐の下を通る本線と高架下の街路 | 590 | 8590 |
| りんくうタウン進入時のJR線とゲートタワー | 1500 | 9500 |
| りんくうタウン駅の上屋・アーチとJRの中央2線 | 1964 | 9964 |
| 連絡橋の中央トラスと海面 | 4500 | 12500 |
| 連絡橋の空港島側から見る旅客機 | 6310 | 14310 |
| 空港島に入った直後の道路と植栽 | 6800 | 14800 |
| 島内道路の下 | 8250 | 16250 |
| 掘割から見る関西空港駅の入口 | 8650 | 16650 |
| 関西空港駅の屋内ホーム | 8890 | 16890 |

走行とATSの回帰検証には `npm run verify:routes` を使います。建築限界は `npm run verify:clearance -- --route=airport` と `npm run verify:clearance -- --route=airport-through` で、それぞれ3種別を検査します。
