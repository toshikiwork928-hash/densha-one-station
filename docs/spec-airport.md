# 南海空港線

トップページで「南海空港線」を選ぶと、岸和田発の通しコース（16.8 km）と泉佐野発のコース（8.8 km）を選べます。この2コースは下りの関西空港行きです。上りは「関西空港 → なんば」を選ぶと、空港急行または特急ラピートβで、泉佐野から本線に入り、なんばまで通して運転できます。泉佐野からりんくうタウンまでは1.9 km、そこから関西空港までは6.9 kmです。[南海電鉄の鉄道事業資料](https://www.nankai.co.jp/lib/company/handbook/pdf/handbook2025_03.pdf)

## 停車駅と時刻

| 種別 | 岸和田から泉佐野まで | 泉佐野から関西空港まで |
|---|---|---|
| 普通 | 各駅に停車 | 各駅に停車 |
| 空港急行 | 岸和田・貝塚・泉佐野に停車 | 各駅に停車 |
| 特急ラピートβ | 岸和田・泉佐野に停車 | 各駅に停車 |

なんば行きの通しコースは42.8 kmです。ラピートβは関西空港、りんくうタウン、泉佐野、岸和田、堺、天下茶屋、新今宮、なんばの順に停車します。空港急行はさらに貝塚、春木、泉大津、羽衣にも停車します。終着駅のATS制動は下りでは関西空港、上りではなんばで働きます。[南海電鉄のりんくうタウン駅上り時刻表](https://www.nankai.co.jp/traffic/jikoku/pdf/rinkutown/a_02.pdf)

ゲーム用のダイヤには、各コースの線形、制限速度、車両性能と終着時の減速を反映しています。アプリのディレクトリで `npm run timetable -- --airport-only` を実行すると、上下3コースの時刻表を再生成できます。

## 駅と景観

| 駅 | ゲームでの表現 |
|---|---|
| [泉佐野](https://www.nankai.co.jp/traffic/station/izumisano.html) | 本線と共通の島式3面4線です。自列車は外側の1番線を出て、空港方面へ右に曲がります。 |
| [りんくうタウン](https://www.nankai.co.jp/traffic/station/rinkutown.html) | 島式2面4線の外側を南海、内側をJRの線路とし、空港側で複線に合流します。 |
| [関西空港](https://www.jr-odekake.net/station/img/premises/0622602.pdf) | 南海とJRに島式ホームを1面ずつ設け、自列車は南海側の1番線に到着します。 |

岸和田から泉佐野までの駅と街並みは既存の本線コースと共通です。空港連絡橋では道路の下を列車が走ります。空港線の曲線、勾配、ホーム寸法、分岐位置、橋やターミナルの形はゲーム用の近似です。JRは線路とホームを再現しています。

## ATSと採点

下りは関西空港、上りはなんばの停止位置まで残り1,500 mで進入を予告し、残り1,000 mから速度を照査します。速度超過が3 km/hを超えると、非常制動が作動します。途中駅では速度超過と停止信号の冒進を採点に反映します。

### 分岐、海上橋、駅前施設

泉佐野を出た空港線の下り線は、上下別の高架で本線の架線を越えます。分岐の下を通る本線には「泉佐野〜みさき公園」コースの線形と勾配を使います。りんくうタウンに入るJR線は、駅の内側2線から内陸へ続きます。JRの取付線形と高架の寸法はゲーム用の近似です。

空港連絡橋は約3.75 kmです。中央部は道路と鉄道が上下に重なる鋼トラス、両岸では道路が鉄道の脇に開く構造として描いています。ゲーム内では海上の橋脚間隔とトラスの部材を簡略化しています。[土木学会関西支部の橋梁資料](https://www.jsce-kansai.net/wp-content/uploads/2019/07/koukyou0726-3.pdf)

りんくうタウンではゲートタワーを、関西空港では第1ターミナルの屋根、エアロプラザ側の建物と立体駐車場を運転台から見える目印にしています。[泉佐野市のりんくうタウン案内](https://www.city.izumisano.lg.jp/izumisano/ikitai/rinkutown.html)・[第1ターミナル設計者の作品解説](https://www.rpbw.com/project/kansai-international-airport-terminal)

### 街並みと景観の確認方法

空港線の沿線データは、OpenStreetMapの建物386件、地上道路679本、駐車場や緑地などの面83件を収録しています。描画時は線路や駅前施設と重なるものを除きます。海上の水面は連絡橋の両岸を基準にした近似です。通しコースは泉佐野で本線と空港線のデータをつなぎます。[OpenStreetMapの出典とライセンス](https://www.openstreetmap.org/copyright)

開発サーバーで `?inspect=1&route=airport` を開き、「運転台」を選ぶと、同じ場所を繰り返し確認できます。通しコースは `?inspect=1&route=airport-through` で開きます。位置欄はコースの座標をメートルで指定します。

| 確認する景観 | 泉佐野発 | 岸和田発 |
|---|---:|---:|
| 泉佐野分岐の下を通る本線と高架下の街路 | 590 | 8590 |
| りんくうタウン進入時のJR線とゲートタワー | 1500 | 9500 |
| 連絡橋の中央トラスと海面 | 4500 | 12500 |
| 空港島に入った直後の道路と植栽 | 6800 | 14800 |
| 関西空港駅手前のターミナルと駐車場 | 8500 | 16500 |

走行とATSの回帰検証には `npm run verify:routes` を使います。建築限界は `npm run verify:clearance -- --route=airport` と `npm run verify:clearance -- --route=airport-through` で、それぞれ3種別を検査します。
