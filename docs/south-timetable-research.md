# 泉佐野以南の平日ダイヤ調査

作成日 2026-10-10。泉佐野〜みさき公園、みさき公園〜和歌山港の2コースで、実際の平日ダイヤを再現するための調査資料。数値はすべて平日ダイヤ（改正日 2024-12-21）。土休日は調べていない。

## 1. 出典と調べ方

- 時刻の原データは鉄道運用Hub（https://unyohub.2pd.jp/railroad_nankai/）の南海の時刻表データ。改正日 2024-12-21、平日。運用表データは CC BY 4.0。南海本線（honsen）と和歌山港線（wakayamakosen）の列車番号、種別、各駅の時刻、前後の接続列車を使った。`scripts/oncoming-meets.ts` が使うものと同じデータで、`node_modules/.cache/unyohub` に一時保存する。リポジトリには入れない。
- Hub の時刻は分単位で、ほとんどが発車時刻。終点だけが到着時刻。到着時刻は無い。したがって駅間の所要時間は、発車から次の駅の発車までの値で、停車時間を含む。秒は出せない。
- 南海の公式サイト（https://www.nankai.co.jp/）の駅時刻表は、取得を試みたが読めなかった。Hub の値を公式時刻表と照合する作業はしていない。
- 運転の傾向の裏づけに、次の記事を読んだ。
  - Wikipedia「南海本線」https://ja.wikipedia.org/wiki/南海本線 の運行形態。日中は特急サザン1時間2本、普通（和歌山市発着）1時間4本。尾崎で普通が特急と接続または待避する（毎時2本）。2024年12月21日改正で区間急行の終着駅が限られた。
  - Wikipedia「南海和歌山港線」https://ja.wikipedia.org/wiki/南海和歌山港線。特急サザン、急行、線内の普通が走る。全線単線で、両駅で行き違いができる。営業キロ 2.8km。最高速度と所要時間の記述は無い。
  - 乗りものニュース https://trafficnews.jp/post/84124 （2019年3月6日）。2019年4月6日改正で、サザンの和歌山市発上りを毎時0分と30分に統一し、尾崎の1・4番線の使用を再開。
  - マイナビニュース https://news.mynavi.jp/article/diagram-71/ （2015年12月14日）。泉佐野〜和歌山市は通勤時間帯を除き特急と普通だけ。日中は特急2本、普通4本。
- 公式の改正が 2024-12-21 より新しいかどうかは不明。確認していない。

## 2. 時間帯と数え方

ゲームの開始時刻は朝 7:30、日中 10:00、夕 17:30、夜 21:30。調べた時間帯は、朝 7〜9時、日中 10〜16時、夕 17〜19時、夜 21〜23時。

本数は、尾崎を通る時刻（尾崎に来ない列車は最初の南側の駅の時刻）がその時間帯に入る列車を数え、時間で割った。Hub の列車は難波から来る列車と、和歌山市で始発になる列車がある。和歌山市〜紀ノ川は加太線と共通運用の普通が走る。これは加太線の列車で、泉佐野以南のコースの種別には入れない。

## 3. 運転パターン（泉佐野より南、1時間あたり）

下りは難波・泉佐野から和歌山市方向、上りは和歌山市から泉佐野方向。

### 日中（10〜16時）

下り
- 普通 毎時4本。難波から来て和歌山市まで全駅に停車。泉佐野から14駅（羽倉崎、吉見ノ里、岡田浦、樽井、尾崎、鳥取ノ荘、箱作、淡輪、みさき公園、孝子、和歌山大学前、紀ノ川、和歌山市）。
- 特急サザン 毎時2本。泉佐野、尾崎、みさき公園、和歌山大学前、和歌山市に停車。
- 空港急行 毎時約4本（泉佐野止まりで空港線へ）、ラピート 毎時2本（泉佐野止まりで空港線へ）。泉佐野以南には来ない。
- 急行、区間急行、準急は無い。
- 折り返し。泉佐野以南で折り返す普通は無い（全部和歌山市まで行く）。羽倉崎へ入る回送が1〜2本。

上り
- 普通 毎時4本。和歌山市から泉佐野まで全駅に停車。
- 特急サザン 毎時2本。和歌山市を毎時0分と30分に発車。和歌山大学前、みさき公園、尾崎、泉佐野に停車。
- 空港急行 毎時4本、ラピート 毎時2本は泉佐野始発。

### 朝（7〜9時）

- 急行 毎時2本。泉佐野、尾崎、みさき公園、和歌山大学前、和歌山市に停車（サザンと同じ停車駅）。
- 特急サザン 毎時1.5本。急行と同じ停車駅。
- 普通 毎時1本が羽倉崎止まり、0.5本がみさき公園止まり。区間急行 0.5本も羽倉崎止まり（泉佐野以南では羽倉崎だけに停まる）。
- 空港急行 毎時4本、ラピートα 毎時1.5本は泉佐野止まり。
- 羽倉崎発着の回送がある。

上り
- 普通 毎時4本が和歌山市から泉佐野まで全駅停車。
- 急行 毎時3.5本。和歌山市、大学前、みさき公園、尾崎、泉佐野に停車。
- 特急サザン 毎時2本。急行と同じ停車駅。
- 羽倉崎始発の普通 毎時1本、区間急行 毎時0.5本。樽井始発の普通 毎時0.5本、みさき公園始発の普通 毎時0.5本。
- 空港急行 毎時4本、ラピートβ 毎時2本は泉佐野始発。

### 夕（17〜19時）

下り
- 普通 毎時2本が和歌山市まで全駅停車。区間急行 毎時1本も、泉佐野から和歌山市まで全駅に停車する（泉佐野以南では普通と同じ停車駅）。
- 急行 毎時1.5本、特急サザン 毎時2本。
- 普通は、羽倉崎止まり 毎時0.5本、樽井止まり 毎時0.5本、みさき公園止まり 毎時0.5本。
- 空港急行 毎時3本、ラピートβ 毎時1.5本は泉佐野止まり。

上り
- 普通 毎時3本が和歌山市から泉佐野まで全駅停車、区間急行 0.5本も全駅停車。
- 急行 毎時1.5本、特急サザン 毎時2本。
- 羽倉崎始発の普通 毎時1本、樽井始発 毎時0.5本、みさき公園始発 毎時0.5本。
- 空港急行 毎時3.5本、ラピートα/β 毎時2本は泉佐野始発。

### 夜（21〜23時）

下り

- 急行 毎時1.5本、特急サザン 毎時2本。

- 空港急行 毎時3.5本、ラピートβ 毎時2本は泉佐野止まり。

上り
- 普通 毎時3.5本が和歌山市から泉佐野まで全駅停車。急行 毎時0.5本。特急サザン 毎時2本。
- 空港急行 毎時3.5本、ラピートα 毎時2本は泉佐野始発。
- 羽倉崎・みさき公園への回送が何本かある。

### 停車駅の確定

- 特急サザン。泉佐野、尾崎、みさき公園、和歌山大学前、和歌山市。和歌山港線に入るサザンは和歌山港まで。
- 急行。泉佐野以南では泉佐野、尾崎、みさき公園、和歌山大学前、和歌山市（和歌山港線に入る急行は和歌山港まで）。サザンと同じ。羽倉崎、吉見ノ里、岡田浦、樽井、鳥取ノ荘、箱作、淡輪、孝子、紀ノ川は通過。
- 区間急行。泉佐野以南の停車駅は2通り。羽倉崎止まり（泉佐野と羽倉崎だけ）と、和歌山市まで全駅停車。
- 空港急行・ラピート。泉佐野だけ。
- 準急。泉佐野以南には来ない。

## 4. 折り返し・始発終着

Hub の平日データで、泉佐野より南にある折り返しと始発・終着。

- 羽倉崎。普通と区間急行が、朝の下り（羽倉崎止まり）と、朝夕の上り（羽倉崎始発）にある。羽倉崎検車区への入出庫の回送もある（夜は和歌山市・みさき公園から羽倉崎へ回送）。
- 樽井。朝の上り（樽井始発の普通が2本程度）、夕の下り（樽井止まり）と上り（樽井始発）。
- みさき公園。朝夕夜に、難波発みさき公園行きの普通と、みさき公園発の普通がある。多奈川線の列車は別系統で調べていない。
- 尾崎、鳥取ノ荘、箱作、淡輪、孝子、和歌山大学前。折り返しは無い。
- 紀ノ川。加太線と共通運用の普通が、和歌山市〜紀ノ川を走って加太線へ入る。
- 和歌山市。通し運転の終着。サザン、急行、普通の多くは和歌山市止まり。一部のサザン・急行・普通は和歌山港線へ入る（6章）。
- 泉佐野。空港線直通の列車の発着駅。泉佐野止まりの普通は、実際は空港線へ入る（泉佐野以南の折り返しではない）。

## 5. 緩急接続・待避

尾崎だけにある。Hub の時刻で、普通が前の駅から尾崎までに通常より2〜5分以上長くかかる場合に、同じ駅で優等列車が発車している時刻と照らし合わせた。尾崎の2・3番線が本線、1・4番線が待避線。サザンも急行も尾崎に停車する。したがって通過待ちではなく、停車する優等列車が先に発車し、普通がその1分後に発車する形。普通の乗客は乗り換えられる。

下りの尾崎（樽井からの所要が通常は3分、待つ列車は6分前後）
- 日中。11時台から毎時2本（樽井発 xx:24 と xx:54 の普通）が、尾崎発 xx:29 と xx:59 のサザンの1分後に発車。10〜11時台前半は待つ列車が無い（10時台に待つ普通は0本）。10〜16時の普通24本のうち9本が待つ。9時台前半にも同じ形がある（例 6827）。
- 朝（7〜9時）。普通7本のうち4本が待つ。相手は急行3本とサザン1本。
- 夕（17〜19時）。普通5本のうち2本が待つ。相手はサザン1本と急行1本。区間急行は尾崎で優等を2本待つ例がある（3803 は樽井 18:41 発 → 尾崎 18:52 発。急行が 18:46、サザンが 18:50 に尾崎発）。
- 夜（21〜23時）。普通8本のうち3本が待つ。相手はサザン1本と急行2本。

上りの尾崎（鳥取ノ荘からの所要が通常は2分、待つ列車は5〜6分）
- 日中。毎時2本（普通の尾崎発 xx:22 と xx:52）が、サザン尾崎発 xx:21 と xx:51 の1分後に発車。10〜16時の普通24本のうち12本が待つ。
- 朝（7〜9時）。普通9本のうち6本が待つ。相手は急行が主で、サザンのこともある。1本（6806）は鳥取ノ荘発 7:12 から尾崎発 7:23 まで11分かかる。サザン6号（尾崎発 7:18）と急行1706（尾崎発 7:20）を続けて待つと読める。
- 夕（17〜19時）。普通7本のうち2本が待つ。相手はサザン1本と急行1本。
- 夜（21〜23時）。普通7本のうち3本が待つ。相手はいずれもサザン。

そのほか
- 上りの普通は泉佐野で長く停まることがある（羽倉崎発から泉佐野発まで中央値で日中 6分、最大13〜14分）。空港線の列車との接続と考えられるが、Hub の時刻からは相手を特定できない。不明。
- Wikipedia に、朝にみさき公園で下りの普通が接続する列車があるという記述がある。Hub の時刻では、みさき公園〜孝子が7分の普通が1本（6813）あるだけで、相手を読み取れない。不明。
- みさき公園、和歌山大学前、和歌山市での待避は見つからなかった。
- 優等が通過する待避（通過待ち）は、駅間の所要時間から読み取れる範囲では、泉佐野以南の平日では見つからなかった。サザンと急行は尾崎に停まる。
