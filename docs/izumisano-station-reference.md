# 泉佐野駅 駅舎・配線の調査メモ

作成日 2026-10-09。`docs/plan-claude-next.md` 8章の下準備。配線は同日に実装した（5章）。建築は6章。
写真は閲覧だけで、リポジトリには保存していない。ここに書く外観は閲覧した写真からの読み取りで、寸法は不明。

## 1. 結論

- 旧コード（`src/route/routes/izumisano.ts`）は3面5線で、実駅の島式3面4線と食い違っていた。2026-10-09 に4線へ直した。決め方と種別ごとの割り当ては5章。
- 屋根は「線路の上を大きく覆う鉄骨の屋根」。既存の `hall`（新今宮・天下茶屋）の作りと近い。ただし完全に閉じたホールではない。

## 2. 配線（確定度が高い）

出典は配線略図.net の `figures/011_06.svg`（泉佐野〜樽井）と、Wikipedia「泉佐野駅」。配線図は南海本線の図で、左がなんば側、上が下り（和歌山側）。

- ホームは島式3面。線路は4本。
- 線路は上（山側・下り側）から、外側下り線、下り本線、上り本線、外側上り線。
- 島式ホームは線路の間に入る。1番ホームは外側下り線と下り本線の間、2番ホームは下り本線と上り本線の間、3番ホームは上り本線と外側上り線の間。
- 下り本線と上り本線は、それぞれ両側にホームがある。両側のドアを開けられる。
- 公式構内図（2013年版）の番線表示は、ホームごとに 1・2、3・4、5・6。下り本線は2番と3番、上り本線は4番と5番の共有。外側の2本が1番と6番。
- Wikipedia の説明は、2・3番と4・5番がそれぞれ線路を共有。3番と4番を介して対面乗り換えができる。
- 当初は山側にもう1面ある4面5線の計画だった。山側のホームが削除され、3面4線で完成した。旧コードの5本目の線路は、この計画の名残を取り込んだ可能性がある。理由は不明。

空港線（りんくうタウン方面）は、配線図で次のように描かれている。
- 下り側は、外側下り線の泉佐野寄りの端から分かれ、本線を斜めにまたいで南側へ向かう。本線との交点は点線で、立体交差の表現。
- 上り側は、外側上り線へ入る。
- 外側下り線と下り本線、外側上り線と上り本線の間に、それぞれ渡り線がある。

不明な点
- 空港急行・ラピート・普通がどの番線を使うか。乗換案内サイトの表示は、空港急行なんば行が5番、普通なんば行が6番、空港急行関西空港行が2番。日によって変わる可能性があり、確定扱いにしない。
- 空港線の分岐器の位置（泉佐野駅から何m）と制限速度。
- 外側下り線と外側上り線が通過線か待避線か。Pixiv百科事典は1番を下り待避線、6番を上り待避線と書く。公式の記述は確認できていない。

## 3. 駅舎の階構造（公式構内図 2013年版と南海の駅ページ）

- 3階がホーム。2階が改札階（ラッチ内の改札口は1か所）。1階が地上。
- 改札階は東西自由通路より少し高い中2階。
- 東出口はバス・タクシー乗り場に面する。西出口もある。2023年9月開業のホテルの建物をくぐった先が東口、という記事がある。
- ホームの両端1両分ずつは柵で仕切られ、立ち入れない。ホーム長は10両分、現在の停車は8両以下。
- 改札階から各ホームへエレベーター・エスカレーターがある。
- 工事の経過は、上り線高架化が2002年、下り線高架化が2005年、新駅舎完成が2006年4月、駅前広場と東西自由通路の完成が2008年10月。2013年版の図と実際で一部違う、と南海が注記している。

## 4. 外観の読み取り（Wikimedia Commons の写真を閲覧）

見た写真は、2013年6月撮影のホーム屋根下、3517の停車写真（外側の線路）、2024年のホーム全景。

- 線路とホームの上に、白い丸柱と鉄骨の梁で組んだ大きな屋根がかかる。屋根は金属板の天井で、縁にルーバー状の透光帯がある。
- 屋根下は斜めの白い鉄骨（V字・K字）で支える。柱はホームの上に立つ。
- 外側の線路の脇は、白〜薄灰色のパネル壁。壁の上は帯状の窓。その上は開いていて空が見える。
- 全面が壁で閉じたホールではない。屋根は複数に分かれ、屋根と屋根の間に空が見える部分がある。
- 屋根の高さ・柱間隔・壁の高さは不明。

## 5. 決定事項と残る確認

決定（ユーザー、2026-10-09）。泉佐野は実駅の島式3面4線にする。理由は、泉佐野から和歌山市までのコースを作るときに、空港線との分岐に影響するため。

- 旧コードの5本（外側下り、下り本線、空港下り、上り本線、外側上り）を、4本（外側下り、下り本線、上り本線、外側上り）に直した。
- 空港線への分岐は、外側下り線の泉佐野寄りの端から出て、本線2本をまたぐ配線として扱う。外側上り線へ空港線の上りが入る。南へ続く本線は、下り本線と上り本線の2本。
- 今後の泉佐野以南のコースは、本線2本から始まり、外側2本は泉佐野構内の待避・空港線専用として扱う前提で作る。現在のコースは泉佐野で終わるので、空港線との分岐そのもの（本線をまたぐ部分）は描かない。外側2本は泉佐野構内の末端（s 8600）で終わる。

### 実装した配線（ゲーム用の概形）

線路の横位置は下りの座標で、進行方向に対して左が負。実寸は不明で、数値は実測ではない。

- 線路: 外側下り線（T1）-9.2、下り本線（T2）0、上り本線（T3）+9.2、外側上り線（T4）+18.4。T2・T3 は `route.tracks` の [0, 4] で、T3 は駅の手前（s 7700〜7950）で 4 から 9.2 へ開く。T1・T4 は追加の線路（`extraTracks`、`izumisano-t1`・`izumisano-t4`）。
- 島式ホーム: P1 -4.6（T1〜T2）、P2 +4.6（T2〜T3）、P3 +13.8（T3〜T4）。幅5.8。線路中心からホーム端まで1.7m。ホームは s 8000〜8220、直線・水平。
- 番線: P1 が 1・2、P2 が 3・4、P3 が 5・6。1番は T1、2・3番は T2 の両側（P1側が2番、P2側が3番）、4・5番は T3 の両側（P2側が4番、P3側が5番）、6番は T4。
- 分岐器: 外側線へ入る列車は 45km/h。下りは s 7700〜8000（後部が抜けるまで）、上りは同じ分岐を鏡像にした泉佐野の手前 350m（下りの s 7650〜8000 に相当）。位置は旧コードのまま。実際の分岐器の位置と制限速度は不明。
- 上りコース（`izumisano-up`）は下りの鏡像（`lat' = 4 − lat`）。

### ゲーム用の割り当て

出典で種別ごとの番線は確定できないため、ゲーム用に決めた。実際の運用とは限らない。本線の2番（乗降）・5番（乗降）は、公式の説明（下り本線は2番が乗降・3番が降車、上り本線は5番が乗降・4番が降車専用）に合わせた。3番・4番側のドアは開けない。

下り（岸和田 → 泉佐野）
- 普通: 外側下り線（T1）、1番、ドア右（P1側）
- 急行: 下り本線（T2）、2番、ドア左（P1側）
- 特急サザン: 下り本線（T2）、2番、ドア左（P1側）
- 空港急行: 外側下り線（T1）、1番、ドア右（P1側）
- 特急ラピートβ: 外側下り線（T1）、1番、ドア右（P1側）

上り（泉佐野 → 岸和田）
- 普通: 上り本線（T3）、5番、ドア左（P3側）
- 急行: 上り本線（T3）、5番、ドア左（P3側）
- 特急サザン: 上り本線（T3）、5番、ドア左（P3側）
- 空港急行: 外側上り線（T4）、6番、ドア右（P3側）
- 特急ラピートβ: 外側上り線（T4）、6番、ドア右（P3側）

方針
- 空港線系統（空港急行・ラピートβ）は外側線（下りは T1、上りは T4）。空港線が外側下り線から分かれ、外側上り線へ入る配線に合わせた。
- 本線系統（急行・サザン）は本線（下りは T2、上りは T3）。
- 普通は変えない。下りの普通は旧コードのとおり外側下り線の1番（待避設定は元々ない）。上りの普通は旧コードのとおり上り本線の5番。変えると停止線・分岐器制限・対向列車の線の割り当てが動くため、今回は動かさない。
- 先行列車（見えない仮想の普通）の扱い: 下りの空港急行・ラピートβは普通と同じ外側下り線に入る。旧コードでは別の線（空港下り線）だったので、先行の普通は終着の泉佐野で自列車と別の番線にいるものとして閉そくから外す（`ServiceSpec.precedingLocalApart`、`src/game/preceding.ts`）。これがないと、先行の普通に塞がれて停止信号が出て、自動運転の所要時間が457秒から482秒に伸び、ATS非常制動が出た。この扱いにして、全種別の自動運転の所要時間が旧配線と同じになった。
- 旧コードとの差は、下りの空港急行・ラピートβが空港専用線の3番から外側下り線の1番になったこと、横位置が変わったこと（上り本線 13.2 → 9.2、外側上り線 22.4 → 18.4、空港下り線 4 を廃止）。ほかの種別の番線・ドア側は旧コードと同じ。停止位置・時刻表・種別の停車駅は変えていない。

対向列車
- 対向列車のデータ（`src/data/oncoming-timetable.json`）は再生成していない。線の対応だけ直した（`src/world/oncoming-timetable.ts`）。下りの空港急行と、なんば方面の自列車と向かい合う下りの普通は T1、上りの空港急行は T4、それ以外は本線。旧コードでは空港急行が専用の空港下り線（3番）だったので、下りの空港急行と普通が同じ T1 を使う点が変わる。両方が同時に泉佐野へ来るときは、既存の進路占有の規則（先行の最後尾から300m以上）で後続が手前で待つ。

検査は `npm run verify:izumisano`（線路4本・島式3面・端1.7m・種別別の走行線・番線・ドア側・分岐器制限）。

残る確認
- 空港線をまたぐ部分が立体交差かどうか。配線図の点線がその表記と推定している。凡例は未確認。
- 空港線の分岐器の位置と制限速度。
- 乗換案内サイトの表示（空港急行なんば行が5番、普通なんば行が6番、空港急行関西空港行が2番）と、ゲーム用の割り当ては一致しない。日によって変わる可能性があり、確定扱いにしない。

## 6. 建築の実装（2026-10-09）

`src/world/station-architecture.ts` の `HALLS` に泉佐野を追加し（`style: 'split-roof'`）、`src/world/custom-stations.ts` の hall 生成経路で描く。寸法はすべてゲーム用の近似で、写真からの実測値ではない。屋根高・柱間隔・壁高・隙間の幅・駅舎の大きさは不明。乱数は使わない。材質は既存の hall と同じ（頂点色の1メッシュ）。

- 屋根: 線路とホームの上を覆う。両側にホームのある本線（下り本線・上り本線）の真上に幅2mの隙間を空け、3枚に分ける。隙間から空が見える。屋根の縁（長辺と短辺）に薄い水色の帯を置いて透光帯とする。高さは線路面から9.4m（近似）。
- 柱: ホームの上だけに立てる。島式ホームごとに、階段口の両脇（ホーム中心から1.6m）へ白い丸柱を対で、12m間隔で立てる。梁（鉄骨）を渡し、柱頭から外へ開く斜材（V字）で屋根を支える。線路の上には立てない。
- 外周: 外側の線路の脇（線路中心から4.2m）にパネル壁（白〜薄灰色、高さ約3.2m）、その上に帯窓（約1.4m）。その上は細い柱と斜材だけで、屋根の縁まで開けている。列車の出入りする両端は壁で閉じない。
- 照明: 夜の照明（`env/night-lights.ts`）の発光体は島式ホームの中央・高さ4.1mに並ぶので、屋根から吊り棒で細いレールを吊って支える。
- 駅舎: 高架の両脇に、低い建物（奥行8m、長さ40m。地面から床版の下まで）を置く。改札階（中2階）の帯窓、地上の出入口と庇を付ける。東口・西口のどちらがどちらの側かは不明なので、両側を同じ形にしている。階段・改札の内部は作らない。従来の高架下の簡易な箱は、泉佐野では出さない（二重にしない）。
- 景観のOSM建物との重なり: 駅舎の位置を、取得済みデータ（`src/data/osm/kishiwada-izumisano.json`）の建物と照合した。左側に約3m×1m、重なる建物が1棟ある。`reserved` は設けていない（道路・緑地まで消えるため）。画面で未確認。
- 架線の門形ビームは、柱と同じ位置に来ると柱と交差して見えることがある。柱の位置を架線の柱に合わせて避けてはいない。画面で未確認。

画面で見る地点は `?inspect=1&route=izumisano` と `?inspect=1&route=izumisano-up` で、`__inspectCam = { s, lat, y, ls, llat, ly }` を使う。例は最終報告に記した。
