# 既存コースの駅舎確認

2026-10-09確認。既存コースの重複を除く27駅を、公式写真・撮影者の写真と照合した。写真は参考に閲覧するだけで、画像ファイルをアプリに収録しない。

今回扱うのは上屋・背面壁・柱・梁の概形。ホーム数、配線、停止位置、運行は変更しない。写真に写らない面、実測寸法、写真撮影後の変更は不明。高さ・屋根長・柱間隔はゲーム用の近似で、写真からの実測値ではない。

- **新今宮** — 線路とホームを覆う切妻の大屋根、外周壁、鉄骨。個別の低いホーム上屋を省き、大屋根と外周柱・帯窓を追加。[2019年の写真](https://commons.wikimedia.org/wiki/File:Platform_of_Shin-Imamiya_Station_(Nankai).jpg)。高野線側を含む全幅の厳密寸法は不明。

- **岸里玉出** — 本線3・4番線は白い鉄骨と斜材の島式上屋。切妻上屋・白い柱・斜材を反映。[南海公式写真](https://www.nankai.co.jp/community/station/kishinosatotamade.html)。高野線・汐見橋線の写真と取り違えない。

## 泉佐野（岸和田〜泉佐野の新コース）

- **泉佐野** — 島式3面4線の高架駅。線路とホームの上に白い丸柱と鉄骨の分割屋根（縁に透光帯、本線の真上に空の見える隙間）、外側の線路の脇は白〜薄灰色のパネル壁と帯窓で、その上は開く。3階ホーム・2階改札階（中2階）・1階地上、東西出口。屋根の高さ・柱間隔・壁の高さ・隙間の幅・駅舎の大きさは写真からの実測値ではなく、ゲーム用の近似。詳細は `izumisano-station-reference.md` 3・4・6章。コードは `station-architecture.ts` の `addSplitRoofHall`。

## 描画と検証

駅名ごとの上屋・壁設定は `src/world/station-architecture.ts`。屋根だけの駅と背面壁のある駅を分け、大屋根は `custom-stations.ts`、羽衣3番線外周は `coastal-stations.ts` が配置する。乱数を消費しないため、沿線の家・木・乗客の抽選順は変えない。

写真から寸法を断定しない。上下の鏡像、乗降端・線路への壁や柱の侵入、屋根の重複をコード・建築限界検査・ブラウザで確認する。27駅の照合は完了したが、撮影後の更新・工事中の形状・省略した配線の完全再現は完了扱いにしない。

2026-10-09の検証結果。`npm run build`、`verify:routes`（朝・夕・夜144運行を含む）、`verify:scenery`、`git diff --check`が成功。駅舎変更後の建築限界は `namba`・`shiokaze`・`kishiwada`・`nankai-through`・`mountain`の各上下、普通/各停の10ケースで違反0群。最後の重複柵整理は壁内の柵の省略だけで、新しい柱・壁は追加していない。新コース上下5種別の建築限界結果は新コース仕様を参照。

ブラウザで新今宮・天下茶屋（両方向）・羽衣・石津川・松ノ浜・高石・高野下・極楽橋と新コースの岸和田・泉佐野を確認。通常画面の新コース選択・開始ボタンの有効化も確認。ブラウザのエラーログは0。独立したコード検証でも線路・乗降口への壁の侵入と大屋根の重複なし。コミット・公開は未実施。
