## 修正

- 汐風線の高架床版・高欄・橋脚を待避線の分岐曲線に合わせて拡幅。相対式高架駅のホームも床版内に収めた。
- 海浜公園の第3線の中心線を描画・床版・架線・検査で共用。レールを勾配に追従させ、上面を本線と同じ約0.383mへ。分岐全域の近景敷地・柵・樹木を避ける。
- 羽根町の支線階段を床版外へ移設し、接続口だけ高欄・ホーム柵を開口。
- 架線柱・引留め柱を全線の外側へ。島式ホームの乗客と標識も建築限界外へ。
- 海浜公園・松原町の踏切をホーム外の5950m・6860mへ。勾配上の道路・踏切板はレール面に追従。

- 樹冠LODは詳細・簡易の両方を包含する固定球を使用。240m前後の形状切替と1400m前後の消去にヒステリシスを追加。旧コードで包含球不足を再現し、修正版で解消を確認。

## 検証範囲と限界

`npm run build`、`npm run verify:routes`、`npm run verify:scenery` を実行。汐風線の下り・上り×3種別と霧峰線の往復で、完走・速度超過0・ATS非常制動0を確認。

`npm run verify:clearance -- --all` は全8ケースで違反0、終了コード0。汐風線は下り普通の修正前142群から0へ、霧峰線は下り43群から0へ。

干渉検査は標本検査であり、実測の鉄道建築限界ではない。実素材は代替形状、BatchedMeshは包囲箱で検査する。車止めだけは意図的な線路閉鎖として明示タグで除外する。

ブラウザで汐風線の合流部・羽根町支線ホーム・道路と路面電車の跨線・鉄橋を確認。霧峰線の1.4km付近でも表示を確認したが、ユーザー報告の点滅とLOD不具合との一致は未確定。細かな表示変化が残る場合は、その地点・方向・視点で追跡が必要。
