# プレイ可能車両の参照とゲーム近似

## 実車資料

1000系は1992年から南海線・高野線向けに導入された軽量ステンレス車である。公式ハンドブックは、VVVFインバータ制御、三相かご形誘導電動機、回生ブレーキ併用・遅れ込め制御付きの全電気指令式電磁直通ブレーキを記載する。南海線では6両固定編成、または2両編成を組み合わせて運用される。ゲームでは1000系6両を普通・急行・空港急行に使用する。

9000系は1985年からの南海線用ステンレス車である。公式は大型前面窓と窓下前照灯を特徴として記載する。原形は他励界磁チョッパ制御・直流複巻電動機だが、2018年開始の更新工事でVVVFインバータ制御・誘導電動機へ変更された。ゲームは更新VVVF車を扱い、4両編成2本による8両の急行・空港急行に使用する。

12000系は2011年導入の特急「サザン」指定席車で、1編成4両、VVVFインバータ制御、軽量ステンレス車体である。公式はサザンを、難波方4両の一般車両と和歌山市方4両の座席指定車両による8両編成としている。ゲームでは12000系を単独選択せず、和歌山市・和歌山港方の指定席4両として、難波方の8300系または9000系の自由席4両と組み合わせる。7100系はこの組合せの対象外とする。

12000系の外観は、公式導入資料に基づき、先頭部から側面上部へ続く青帯と、側面下部の青・橙の曲線帯を表現する。公開資料で確認できない運転台や細部はゲーム用の簡略表現とする。

## ゲーム内の近似

9000系は4両編成2本による8両の急行・空港急行を基本とし、サザン12000系の相手として4両でも生成する。窓割は既存7100系と同じ規則を用いる。

公式一次資料では、1000系・9000系更新車・12000系の起動加速度、常用最大減速度、非常減速度、営業最高速度を確認できていない。ゲーム内のこれらの性能値は実車仕様の断定ではなく、既存車両との運転感をそろえるためのゲーム近似である。

ゲーム値は1000系・9000系とも起動加速度2.5km/h/s、常用最大減速度4.32km/h/s、非常減速度5.22km/h/s、車両最高速度110km/h。12000系は起動加速度2.5km/h/s、常用最大減速度3.7km/h/s、非常減速度4.0km/h/s、車両最高速度120km/hとし、営業最高110km/hの案内表示と区別する。運行時は路線・種別の制限速度も適用する。

12000系は4両固定。サザン指定席側として使用し、8300系または9000系の4両自由席側と組み合わせる。

外観はThree.jsの手続き生成で作り、外部画像アセットは使用しない。実車確認できない細部はゲーム用の簡略表現である。
