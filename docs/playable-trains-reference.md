# プレイ可能車両の参照とゲーム近似

## 実車資料

7100系の外観は、青と橙の帯を巻いた通常塗装をモデルにした。前面は貝塚―二色浜間で撮影された7957号車を参考に、屋根肩の丸み、中央の貫通扉、左右の窓、左窓上の表示器を配置した。側面はモハ7189とサハ7847の写真に合わせ、先頭車と中間車で扉の位置と車端の窓数を描き分けた。7166号車の写真に合わせ、中央の貫通扉から左右の窓の外側へ向かって前面を緩やかに後退させた。三枚の窓はガラスの上下端をそろえた。スカートは7965号車を参考に、中央を開けて連結器とホースが見える形とした。寸法と色調は写真からの近似である。

復元塗装の7169編成は4両で1本。南海本線・空港線では単独4両のほか、新塗装7100系を2両または4両つないだ6両・8両を選べる。8両で停車すると最後尾が踏切にかかる運行では、4両・6両から選ぶ。特急サザンでは10000系の自由席側として連結する。自車が7169編成を使う運行では、対向・待避・追い越し列車に復元塗装は登場しない。難波方の先頭車を7169号、和歌山市方を7170号とし、運転方向に合わせて表示する。

モハ7189の側面写真では、乗務員室寄りのパンタグラフが横から菱形に見える。模型では下枠を台枠のすぐ上で交差させ、前後の関節を最も広く開いた。上枠はその関節から中央の集電舟を支える。

1000系は1992年から南海線・高野線向けに導入された軽量ステンレス車である。公式ハンドブックは、VVVFインバータ制御、三相かご形誘導電動機、回生ブレーキ併用・遅れ込め制御付きの全電気指令式電磁直通ブレーキを記載する。南海線では6両固定編成、または2両編成を組み合わせて運用される。ゲームでは1000系6両を普通・急行・空港急行に使用する。

9000系は1985年からの南海線用ステンレス車である。公式は大型前面窓と窓下前照灯を特徴として記載する。原形は他励界磁チョッパ制御・直流複巻電動機だが、2018年開始の更新工事でVVVFインバータ制御・誘導電動機へ変更された。ゲームは更新VVVF車を扱い、急行・空港急行では単独6両、同系4＋4両、9000系4両と8300系2両2本の混結を選べる。

12000系は2011年導入の特急「サザン」指定席車で、1編成4両、VVVFインバータ制御、軽量ステンレス車体である。公式はサザンを、難波方4両の一般車両と和歌山市方4両の座席指定車両による8両編成としている。ゲームでは12000系を単独選択せず、和歌山市・和歌山港方の指定席4両として、難波方の8300系または9000系の自由席4両と組み合わせる。7100系はこの組合せの対象外とする。

12000系の外観は、公式導入資料に基づき、先頭部から側面上部へ続く青帯と、側面下部の青・橙の曲線帯を表現する。公開資料で確認できない運転台や細部はゲーム用の簡略表現とする。

## ゲーム内の近似

9000系は急行・空港急行で8両編成を基本とし、サザン12000系の相手として4両でも生成する。側面は4か所の客用扉の間に窓を2枚ずつ配置する。

公式一次資料では、1000系・9000系更新車・12000系の起動加速度、常用最大減速度、非常減速度、営業最高速度を確認できていない。ゲーム内のこれらの性能値は実車仕様の断定ではなく、既存車両との運転感をそろえるためのゲーム近似である。

ゲーム値は1000系・9000系とも起動加速度2.5km/h/s、常用最大減速度4.32km/h/s、非常減速度5.22km/h/s、車両最高速度110km/h。12000系は起動加速度2.5km/h/s、常用最大減速度3.7km/h/s、非常減速度4.0km/h/s、車両最高速度120km/hとし、営業最高110km/hの案内表示と区別する。運行時は路線・種別の制限速度も適用する。

12000系は4両固定。サザン指定席側として使用し、8300系または9000系の4両自由席側と組み合わせる。

外観はThree.jsの手続き生成で作り、外部画像アセットは使用しない。実車確認できない細部はゲーム用の簡略表現である。

## パンタグラフと前面の構造

編成ごとに難波方から車両を数え、各車の難波寄り・反対側・両端のどこに集電装置があるかを記録した。運転方向と最後尾の車体回転を別々に反映する。1000系6両では1・3両目、50000系6両では2・5両目に各2基を載せる。形式内に複数の編成がある場合はゲーム用の代表編成を選んだ。車端から台枠までの距離は写真からの近似値である。

前面の輪郭は車体の断面から生成する。6300系は7100系と前面窓・貫通扉・肩の曲面を共有し、ステンレス外板を描き分ける。30000系は腰が最も張り出し、そこから展望窓が屋根側へ後退する断面とした。8300系・12000系のスカートは車体の角に沿って側面へ回り込む。

## 車体外観の写真照合（2026年11月）

6300系は6301号を基準にした。前面と側面の青帯・橙帯は同じ上下端、色、材質を使う。青帯の波板は角まで続き、乗務員扉の扉板には平らな帯を描く。9000系は9501号の写真と照合し、前照灯の中心を車体中心から左右1.01 mに置いた。左右の前面窓だけに深緑の日よけを描き、中央窓は素のガラス色を保つ。

2000系の側面は2039編成のモハ2039とモハ2189を参照した。車体長で写真の横座標を正規化し、乗務員室側から24.4%と76.3%の位置に客用扉の中心を置いた。扉間の3組と連結面寄りの1組には中桟がある。乗務員扉と客用扉の間は1枚窓である。モハ2039の両パンタグラフの間には、車体長の約半分を占める冷房カバーを載せた。写真から読んだ比率はモデルの近似値である。[モハ2039の側面](https://railfile.jp/nankai/car/2024/06/2039.html)・[モハ2189の側面](https://railfile.jp/nankai/car/2024/06/2189.html)・[同編成の前頭部と屋上写真](https://note.com/coupy1xb/n/n1e389722dd74)

12000系は12101号の近接写真と編成写真を使い、中央扉の両脇から側窓の外端に向かって前面を後退させた。前面、側板の角、灯具は同じ曲線をたどる。10000系は10909号の写真に合わせ、前面ガラスが側面に回り込む部分の後端を傾けた。下端は上端より乗務員扉に近い。[12101号の側面](https://railfile.jp/nankai/car/2011/07/12101.html)

1000系は1510号と1703号、8300系は8360号と8407号の写真で正面と斜めを照合した。ラピートは添付写真と50706号の側面を使い、前頭部の稜線、三段の灯具、乗務員扉と客用扉の間の楕円窓11枚を表現した。ガラスには背景の映り込みを描き込まず、運転台の窓枠とワイパーで輪郭を示す。客室や床下機器には簡略化した形状を使う。[1002号の側面](https://railfile.jp/nankai/car/1992/03/1002.html)・[8310号の側面](https://railfile.jp/nankai/car/2022/03/8310.html)・[50706号の側面](https://railfile.jp/nankai/car/1994/09/50706.html)

## 運転士から見た運転台

運転台は進行方向の先頭車に合わせて切り替わる。サザンは、同じ編成でも難波方では自由席車、和歌山市方では指定席車の運転台が見える。7100系の通常塗装車と復元塗装車は同じ運転台を使う。

| 系列 | 運転席から見える主な特徴 |
| --- | --- |
| 7100系・6300系 | 窓台のワイパー機構、横一列の丸計器5個、右奥の行路表示器。7100系は淡い灰色、6300系は濃い灰色の計器盤。 |
| 8300系 | 黒い計器台に丸計器3個。右の行路表示器の上に車両モニター。 |
| 1000系・50000系 | 横長の黒い盤にデジタル速度計。ラピートは高い着座位置から濃青の日よけ越しに前方を見る。 |
| 9000系・2000系 | 左の窓柱に縦2段の計器。9000系は濃紺の主計器盤、2000系は暖色の文字盤。 |
| 2300系・30000系 | 2300系は丸計器のある灰色の卓。30000系は低い横長の計器盤と傾斜した広い前面窓。 |
| 10000系・12000系 | 10000系は濃紺の台にクリーム色の丸計器5個。12000系は灰色の卓に丸計器をまとめた。 |

窓枠、ゴム縁、計器台、機器はゲーム内で立体を生成する。窓の寸法、目の高さ、計器の目盛や機器の細部は運転画面に合わせた近似値である。速度、時計、戸閉灯にはゲームの状態を反映する。圧力と電流には簡略値を使う。

運転台の配置と色調は、Bve 南海・泉北線プロジェクトの各系列の掲載画像を参照した。[7100系](https://wadynankai.ddo.jp/nankaiPJ/7100.html)・[6300系](https://wadynankai.ddo.jp/nankaiPJ/6300.html)・[8300系](https://wadynankai.ddo.jp/nankaiPJ/8300.html)・[1000系](https://wadynankai.ddo.jp/nankaiPJ/1000.html)・[9000系](https://wadynankai.ddo.jp/nankaiPJ/9000.html)・[2000系](https://wadynankai.ddo.jp/nankaiPJ/2000.html)・[10000系](https://wadynankai.ddo.jp/nankaiPJ/10000.html)・[50000系](https://wadynankai.ddo.jp/nankaiPJ/50000.html)

### 前面窓と貫通扉

貫通型の9系列では、運転席の窓、中央の貫通扉、助士席の窓を別々に作った。扉には窓ゴム、戸当たり、蝶番、引き手を設けた。1000系の扉窓は下方まで伸ばし、2300系は小窓にした。30000系は非貫通の展望窓、ラピートは中央の窓柱と日よけを持つ前面として描く。[1000系の参考画面](https://wadynankai.ddo.jp/nankaiPJ/1000.html)・[30000系の運転台写真](https://toyokeizai.net/articles/photo/750336?pn=11)

運転席の視点は左の正面窓と主計器の中心に合わせた。ラピートを除く各系列で窓の上辺を高くし、視線を水平より少し上に向けて架線が見える範囲を広げた。7100系は窓台の駆動箱から伸びる二本のワイパーアームと右の縦型表示器、1000系はマイク、右窓柱の通話装置、黒い一体盤の位置を添付の参考画面に合わせた。Bveの掲載画像は運転士目線の構図の資料として使った。窓や扉の寸法はゲーム内の近似値である。[7100系の参考画面](https://wadynankai.ddo.jp/nankaiPJ/7100.html)
