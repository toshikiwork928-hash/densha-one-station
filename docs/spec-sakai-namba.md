# 仕様と調査: 南海本線 堺〜なんば

作成日: 2026-10-07。実装は `src/route/routes/namba.ts`（内部 ID `namba`）。計画段階のメモは [plan-sakai-namba.md](./plan-sakai-namba.md)。

## 1. 位置づけ（ユーザー指定）

- 堺 → なんば（終点）の1方向だけ。描画が多いので、岸和田までの通しは作らず独立のコース。
- 終点なんば: 特急ラピートは9番線（8番線併用）、普通は7番線、急行・空港急行は6番線、特急サザンは5番線。
- 高野線（天下茶屋〜なんば）は車両データを増やさず、8300系・2300系を描画だけで走らせる。
- 完全再現ではなく「それっぽい」概形。

## 2. 駅と距離

営業キロ（難波起点、Wikipedia 南海本線の駅一覧）: 堺 9.8 / 七道 8.2 / 住ノ江 6.7 / 住吉大社 5.7 / 粉浜 5.1 / 岸里玉出 3.9 / 天下茶屋 3.0 / 新今宮 1.4 / 難波 0.0。
ゲームの停止位置は堺から 0 / 1.6 / 3.1 / 4.1 / 4.7 / 5.9 / 6.8 / 8.4 / 9.8km（100m 単位）。駅名の表示は「なんば」。

OpenStreetMap（Overpass API で南海本線の線路形状を取得、2026-10-07）の堺→難波の最短経路は 9.83km。駅中心の位置は営業キロとほぼ一致した（七道 1.60 / 住ノ江 3.19 / 住吉大社 4.06 / 粉浜 4.67 / 岸里玉出 5.90km）。

| 種別 | 停車駅 |
|---|---|
| 普通 | 全駅 |
| 急行・空港急行・特急サザン・特急ラピート | 堺・天下茶屋・新今宮・なんば |

萩ノ茶屋・今宮戎は高野線だけの駅（本線にホームなし）。コースの駅には含めず、景観として島式ホームを描く。

## 3. 線形・構造（OSM から読んだ概形）

- 方位: 堺〜七道は北東へ直線、七道の北で左へ約28°（R≈660、80km/h）、住ノ江の手前で右へ約8°、住ノ江の先で左へ約12°（95km/h）、以降は北北東へ直線、なんばの手前で左へ約43°（R≈375、構内 45km/h）。なんばのホームは直線。
- 全線高架（9m）。大和川橋梁（OSM の橋 約220m）は 鋼桁（下路プレートガーダー）／鋼トラス／鋼桁 の緑色の鋼橋。七道を出てから大和川を渡り切って約300mは壁のない高架（ユーザー指定）。
- 新今宮: JR（大阪環状線・大和路線）の上を越えるため、ホームの手前で 25‰ で上って 15m、今宮戎の先で 12m へ下りてなんばへ（OSM の layer=2 区間から）。JR は新今宮のホームの下をほぼ直角に横切る（描画のみ）。
- 住ノ江検車区: OSM の yard は住ノ江駅の西（左）、s 約 3.1〜3.6km、線路から 15〜110m。高架上の留置線と検修庫を描く（`world/suminoe-depot.ts`）。

## 4. 配線（配線略図.net figures/011_01.svg・011_02.svg と OSM）

横位置（進行方向左が負、上り本線 = 0）:

| 区間 | 線路 |
|---|---|
| 堺〜住ノ江 | 複線（上り 0・下り 4） |
| 住ノ江〜岸里玉出 | 複々線: 上り緩行 0・上り急行 4・下り急行 8・下り緩行 12。普通は外側の緩行線、優等は内側の急行線。住ノ江・住吉大社・粉浜は島式2面4線（緩行線がホームの外へ開く） |
| 岸里玉出 | 本線は島式1面2線（難波側は複線）。左端に汐見橋線の行き止まりの線と片面ホーム（2300系が停車中） |
| 岸里玉出〜なんば | 本線（0・4）の右に高野線（上り 9・下り 13）。高野線は岸里玉出の先で右から合流 |
| 天下茶屋・新今宮 | 片面（上り本線の左）・島式（下り本線と高野線上りの間）・片面（高野線下りの右） |
| なんば | 頭端式 9面8線。左から 9番線（8番線併用）-18・7番線 -6・6番線 +6・5番線 +18・4〜1番線（高野線）+30〜+66 |

- 優等列車の進路: 住ノ江の手前で急行線へ（分岐器 70km/h）、岸里玉出の手前で本線へ戻る（60km/h）、なんばの手前で種別の番線へ。
- 番線の配置・分岐器の位置は概形（実物の渡り線の数・位置は再現していない）。

## 5. 実装の仕組み（汎用）

- `LatProfile`（`[s, 横位置][]`、点の間は余弦の S字）で線路の横位置を表す。
  - `Route.trackProfiles`: `route.tracks`（0・4）の横位置の変化（複々線で下り線が外へ、駅で開く、なんばの番線へ）
  - `Route.extraTracks`: 追加の線路（上り急行線・下り緩行線・高野線・番線・渡り線・汐見橋線・入出庫線）。線路・架線・床版・景観の除外・建築限界の検査に使う
  - `ServiceSpec.lane` / `laneLimits` / `platformSides` / `trackNames`: 種別ごとの走行線・分岐器の制限・ドアの側・到着番線
- `Station.layout = 'custom'` と `customPlatforms`: 島式・片面ホームを並べる駅（`world/custom-stations.ts`）。`external` は専用モジュールが描く（なんば）
- `Route.reserved`: 景観（住宅・ビル）を置かない敷地。`noPiers` は高架の橋脚を立てない範囲（JR の真上）
- `Route.urban`: 海・工業地帯の遠景の代わりに、中高層ビルの遠景と街区の箱で埋める。地面も灰色がち
- `Structure.open`: 壁（高欄）の低い高架。`Route.bridgeStyle`: 鋼橋の色と下路プレートガーダー

## 7. 未対応・制限

- 逆方向（なんば → 堺）は無い。
- 高野線・下り緩行線の電車は描画だけで、信号・閉そくには関わらない。
- 先行の普通（見えない列車）は優等列車と同じ線路として扱うため、時隔を大きくして追いつかないようにしている（`precedingHeadway`）。
