# densha-one-station

運転台視点で電車を運転するブラウザゲーム（往年の運転ゲーム風）。「南海本線」（堺〜泉大津・泉大津〜岸和田の2区間）と「高野線」（橋本〜極楽橋）を運転する。Three.js + Vite + TypeScript 製。

## 目的

Three.js で運転台視点の3D表現・簡易列車物理・スコアリングを作る練習。並行開発しやすいモジュール構成（イベントバス＋共有コンテキスト）の練習も兼ねる。

## 状態

遊べる試作。南海本線 泉大津 → 堺（10.6km・10駅）と山岳路線の高野線 橋本 → 極楽橋（一部の駅を省略した5駅）を収録。駅名・駅間距離・配線は泉大津〜堺（実在）を参考に再構成（公式の再現ではない概形）。参照資料と概形の限界は [docs/shiokaze-reference.md](./docs/shiokaze-reference.md)、山岳編との並行統合は [docs/integration-handoff.md](./docs/integration-handoff.md)。今後の案は [ROADMAP.md](./ROADMAP.md)。

- **運転**: マスコン P1〜P5 / N / B1〜B8 / EB。ブレーキ立ち上がり遅れ・走行抵抗・勾配抵抗・天候による粘着低下
- **信号・ATS**: 4灯式（R / Y 45 / YG 65 / G）。見えない先行列車の在線で現示が変わる。制限超過や停止信号接近で ATS 警報 → 5秒以内に B4 以上＋確認（`A`）が無ければ非常制動。停止信号冒進も非常制動
- **南海本線の終着入線**: 終着の低速進入 ATS（連続速度照査・非常制動）は無効（`route.terminalApproach: false`、機能は `src/game/terminal-ats.ts` に残置）。代わりに普通は堺 3番線・泉大津 1番線（待避線側、急行・特急との連絡を想定）へ入線し、分岐器制限 45km/h を守る。標識・予告・放送・バナーで番線と制限を案内。急行・特急は本線ホームへ制限なしで通常停止。モデルの泉大津・堺は本線途中駅なので車止めは置かない
- **駅**: 始発駅もドアが開いた状態から始まり、発車メロディ → 戸閉め（チャイムと閉扉音の約3.5秒は発車不可、閉まり切ると戸閉灯）→ 出発信号が進行なら力行で発車。定刻に閉まり切るよう戸閉めする。途中駅も同じ。通過駅で止まると減点
- **時刻表パネル**: 最大10行。駅の多いコース（堺〜岸和田の通し）は、次の停車駅の2駅前から表示し、過ぎた駅は上へ送って消す
- **時刻表**: `npm run timetable` が両路線の種別ごとの自動運転から到着・通過時刻を計算し、走行時間に+5%の余裕を足す。終着の待避線入線（普通）の分岐器制限も計算に含める。`npm run timetable -- --shiokaze-only` は南海本線だけ再生成し、山岳線の時刻表を変更しない
- **ラッシュ時の対向列車**: 南海本線（複線）は時間帯が朝・夜のとき、対向の停車列車がいない途中駅にも停車する対向の普通を追加（下り・上りとも3本）。高野線（単線）は交換駅のダイヤに影響するため変更しない
- **時計**: 時間帯に合わせて始発時刻が変わる（朝 7:30 / 昼 10:00 / 夕 17:30 / 夜 21:30。時刻表は相対時刻のまま平行移動）
- **ステージとモード**: 選んだ種別の停車駅間ごと＋全線通し。モードは 通常 / 遅延回復（遅れて発車）/ 定時運転（時間と安全のみ採点）。自己ベストは種別ごと
- **採点**: 停止位置・定時・安全（速度超過・EB・停車時衝動・ATS・誤停車で減点）。駅ごとの結果表、自己ベストを localStorage に保存。停止位置±0.3m で「ピッタリ」、15m 超の行き過ぎで失格
- **リプレイと視点**: 結果画面で `R` を押すと沿線カメラ・追従・空撮を切り替えるリプレイ。運転・停車中は `V` で 運転台 → 俯瞰追従 → 前方斜め → 編成全景。俯瞰追従・リプレイは従来の配置を保持。側面アップを、顔と側面を見る前方斜め、編成全体を見る全景へ変更。全景は編成長・曲線・勾配・画面比率に応じて距離を調整する。
- **車両プレビュー**: 車両タブに実モデルから描いた顔アイコンと3D外観展示。正面・斜め・側面・屋根、回転・拡大縮小、先頭車 / 選択編成の全体を切り替えられる。展示は昼の照明で、ゲーム側の天候や車両材質は変更しない。展示が見えている時だけ必要に応じて描画する。
- **環境**: 時間帯（朝・昼・夕・夜）と天候（晴れ・雨・雪・霧、強さ可変）。スカイドーム・太陽と月・星・雲、影、窓の雨粒とワイパー、積雪、トンネル内の暗転。夜は前照灯・ホーム照明・沿線の街灯・窓明かりが点灯し、時間帯の切替に合わせて連続的に変化する。画質は 低 / 中 / 高
- **ビジュアル**: 20m 級4扉の通勤電車（架空塗装）を手続き生成（自列車・対向列車）。7100系は前照灯が前面上部中央の丸い2灯、下部左右は標識灯（先頭のとき普通は前から見て左だけ、急行・特急は両方点灯。最後尾は両方赤）。10000系（サザン）は貫通型の前面（上半分が黒・下半分が青、行先表示は中央上部）で、中間車は連続した横長の窓。2300系・8300系の行先表示は左が種別・右が行先。岸和田は屋内式の駅（ホームに入ると外が見えず、照明と反響が変わる）、泉大津駅前に2棟並びのタワーマンション（架空の外観）。3D 運転台（マスコン・速度計・圧力計・戸閉灯・行路表が連動）。日本の街並み（戸建て・アパート・マンション・商店・架空のコンビニ・自販機・電柱と電線・田畑・竹林）、踏切（遮断かん・警報灯が連動、待機車両）、トンネル坑口・高架橋・橋梁と川。駅前ビルと木は CC0 の 3D 素材
- **音（すべてコード合成。録音サンプル不使用）**
  - VVVF: 非同期 → 同期 27P/15P/9P/5P/3P → 1パルスの音程階段、電動機の高調波、歯車音。回生ブレーキは逆順、5km/h付近で失効。改良音は低い起動音から立ち上げ、高域の倍音・2.8kHz付近・歯車音を抑え、低いうなりと加速に伴う音量変化を調整。停止中に力行を入れただけでは高い音を立ち上げない。サウンドタブの「走行音」で改良（既定）/ 従来を比較でき、選択は保存。実車の録音や制御値の再現ではなく独自合成（VVVF車のみ対象）
  - 走行音: 転動音・風切り・高架の空洞音・急曲線のフランジ音。継ぎ目は台車配置どおりにタタン・タタン。トンネルは ConvolverNode 残響
  - 空気ブレーキ・コンプレッサ・ブレーキ鳴き、ドアチャイム・ドア開閉・オリジナル発車メロディ・ホームのざわめき
  - 車内放送: Web Speech API（ja-JP 音声がある環境のみ。無ければ無音）。声は端末（ブラウザ・OS）の日本語音声に任せる（加工しない）。駅名はカタカナで渡して読み間違いを防ぐ。始発駅の発車後は挨拶と行先、終点の手前は御礼、普通は待避駅で「待ち合わせ / 通過待ち」と発車時の「お待たせしました」、急行は接続駅で「普通車にお乗り換えになれます」。普通は待避駅の到着前の放送でも「○○で特急ラピートの通過待ちをします」と案内する。放送・行先表示の行先はコースの終点ではなく列車の本来の行先（`ServiceSpec.destination`）: 堺方面は全種別「なんば」、和歌山方面は 普通 羽倉崎・急行 和歌山市・空港急行 関西空港・特急ラピート 関西空港・特急サザン 和歌山港（例「この電車は、空港急行、関西空港行きです」「この電車は、特急ラピート、なんば行きです」。サザンは「一部座席指定、特急サザン{行先}行き」）。行先が区間の終着駅と違う列車は終着駅を「終点」と言わない（普通の終着駅の番線案内は従来どおり）
  - ATS ベル/ブザー、速度超過ブザー、空気笛、踏切警報（距離減衰・ドップラー）、雨音、すれ違い
- **描画負荷の工夫**: 手続き生成物は材質ごとに結合（300m チャンク）、読込素材は材質ごとの `BatchedMesh` に集約（個体単位の視錐台カリング）、木は距離で簡易形状へ切替、遠方のチャンク・枕木・標識・信号・踏切は距離で非表示。描画コールは中画質で約 110〜180（影パス込み）

## 操作

### 描画比較（試作）

画面左下の「描画：イラスト / 標準」で即切替。走行状態・時間帯・天候は保持する。
イラスト描画は柔らかな3段階の直射光、冷色の環境光、車体の細い輪郭線と縁の陰影、地面の濃淡、建物の接地影、遠景の霞を追加する。
夜・トンネルでは効果を弱める。モデル・信号色・運転処理は変更しない。

- イラスト（既定）: `http://localhost:8765/?look=illustrated`
- 元の描画: `http://localhost:8765/?look=standard`
- 実装: `src/render/illustrated.ts`。依存追加なし。
- ソースごと戻す場合: `main.ts` の `attachIllustratedLook` の import・呼出しを外し、`town-jp.ts` の `shadowChunks`・接地影生成/配置と `train-models.ts` の `train-shell` 命名を戻す。この節と追加ファイルも不要になる。今回の追加は1つのコミットにまとめてあるため、そのコミットを revert すれば車両展示・視点変更も含めて元へ戻せる。

## 実行方法

開発時の検証:

- `npm run verify:routes`: 堺〜なんば（5種別の完走・番線・複々線の走行線）、両路線の往復運行、南海本線（堺〜泉大津）4種別・（泉大津〜岸和田・堺〜岸和田）5種別（空港急行の8両・6両の完走を含む）、行先・放送文面、終着入線（普通45km/h・急行/特急は制限なし）・ATS非常制動0・速度超過0を検証。
- `npm run verify:scenery`: 樹冠LODの包含球と距離境界の反復切替を検証。
- `npm run verify:clearance`: 全コース（堺〜なんば を含む）の構造物干渉を標本検査。数分かかる。`-- --route=shiokaze --service=local` で対象を絞れる。
- `npm run dev` の `?inspect=1&route=shiokaze` / `shiokaze-up` / `mountain` / `mountain-up`: 駅・構造物選択、任意の距離入力、外部視点で点検。

干渉検査は描画なしの近似。素材の木・ビルは代替形状、BatchedMeshは包囲箱、三角形は0.4m間隔で判定する。車止めは意図的に終端を塞ぐため除外。車両・地面・電線も対象外なので、架線との離隔や読み込んだ実素材は目視でも確認する。

```bash
cd apps/densha-one-station
npm install
npm run dev        # 開発サーバー（http://localhost:8765）
npm run typecheck  # 型チェック
npm run verify:routes # 南海本線6運行・山岳線2運行、終着入線・ホーム直線・橋梁非干渉の回帰確認
npm run build      # dist/ へ本番ビルド（base: './' のため GitHub Pages のサブパスでも動作）
npm run preview    # ビルド結果の確認
```

開発時の `?inspect=1` は駅・跨線橋・支線の景観確認画面。`&route=shiokaze-up` で復路を確認できる。本番ビルドでは読み込まない。
終着の低速進入 ATS は無効（`terminalApproach` を true にすると残り1500mで予告、1000mから速度照査）。

スマホ（タッチ端末・短辺600px未満）は画質を中・高にしてもDPR 1、動的影なし、MSAAなしで描く。PCの画質設定は従来どおり。
GPU接続消失・描画例外・シェーダー失敗では低画質へ退避し、3Dに依存しない再読込ボタンを表示する。
起動・画質変更直後に描画が完了せず再読込した場合も、同じタブでは低画質に退避する。
操作できない時はURLに `?safe=1` を付けて開くと画質だけを低へ戻せる。記録・車両・音設定は保持する。
開発時 `?render-test=1` にはGPU接続消失の模擬ボタンを表示する。本番には含めない。

並行作業用に `.claude/launch.json`（worktree ルート）へ `densha`(8765) / `densha-a`〜`densha-d`(8771〜8774) を定義。開発時は `window.__densha` で GameContext を参照できる。

旧単一ファイル版は `legacy/index.html`（参照用。CDN import map 版でそのままブラウザで開ける）。

### 公開用リポジトリの更新

公開は、このディレクトリの中身をルートに置いた独立の公開 repo で行う（この個人 repo からは直接公開しない）。

1. このディレクトリを公開 repo へコピー（`node_modules/` と `dist/` は除く）
2. `deploy/pages.yml` を公開 repo の `.github/workflows/pages.yml` として置く
3. 公開 repo の Settings > Pages > Source を「GitHub Actions」にする
4. 公開 repo の `main` へ push すると `npm ci && npm run build` → `dist/` が GitHub Pages へ公開される

## 公開可否

可。3D素材はすべて CC0（帰属表示不要だが出典を記載）。ゲーム内の店名・塗装は架空。南海本線は泉大津〜堺、高野線は橋本〜極楽橋（一部の駅を省略）の実在の区間を参考にした概形で、公式の再現・監修ではない。調査資料に実在の駅名・事業者名を出典として記載するが、公式ロゴや実車録音は収録しない。
