# densha-one-station

運転台視点で電車を運転するブラウザゲーム（往年の運転ゲーム風）。架空の「汐風線」「霧峰線」を運転する。Three.js + Vite + TypeScript 製。

## 目的

Three.js で運転台視点の3D表現・簡易列車物理・スコアリングを作る練習。並行開発しやすいモジュール構成（イベントバス＋共有コンテキスト）の練習も兼ねる。

## 状態

遊べる試作。汐風線 桜ヶ丘 → 岬口（10.6km・10駅）と山岳路線の霧峰線 川原町 → 雲ノ橋（5駅）を収録。汐風線の距離・駅配置は南海本線の泉大津〜堺を参考に再構成。参照資料と概形の限界は [docs/shiokaze-reference.md](./docs/shiokaze-reference.md)、山岳編との並行統合は [docs/integration-handoff.md](./docs/integration-handoff.md)。今後の案は [ROADMAP.md](./ROADMAP.md)。

## 内容

- **汐風線**: 桜ヶ丘 → 松浜 → 北松原 → 白浜台 → 羽根町 → 海浜公園 → 松原町 → みなと川 → 汐見町 → 岬口。駅間は順に0.9 / 1.0 / 1.2 / 1.7 / 0.8 / 1.0 / 1.1 / 1.5 / 1.4km。高架7駅、地上3駅（北松原・海浜公園・松原町）、緩い沿岸曲線と高架への±20‰勾配。道路跨線橋2か所、路面電車の跨線橋、みなと川の鋼トラス橋、羽根町の描画専用高架支線、地上区間の踏切5か所を配置。トンネルは置かない。平面曲率・構造物位置・寸法・9mの高架高さは実測ではなくゲーム用の概形
- **汐風線の運行種別**（タイトルで選択。上りは逆順）: 普通（4両 または 4+2 の6両・最高90km/h・全駅停車。白浜台で急行の通過待ち）/ 急行（6両 = 4+2、8両 = 4+4 または 4+2+2・最高100km/h・桜ヶ丘、羽根町、岬口に停車）/ 特急（特急形6両固定・最高110km/h・桜ヶ丘、岬口に停車）。普通・急行は車両タブで 8300系（新型通勤車・VVVF）/ 7100系（旧型通勤車・抵抗制御）と編成を選べる。車種ごとに加速性能とブレーキが異なる。全駅ホーム220m、4両/6両/8両の停止位置目標を表示。種別ごとに時刻表・停車駅・制限解除位置（後部通過）・自列車の外観が変わる。停車パターンと時刻表はゲーム用
- **霧峰線**: 川原町 → 清流口 → 杉ノ沢 → 霧ヶ谷 → 雲ノ橋。単線の山岳路線、最大50‰の勾配、急曲線、橋梁とトンネル。2300系の各停（2両/4両）で、交換駅の行き違いを扱う
- **上り**: タイトルの方向で 岬口 → 桜ヶ丘 を選べる（下りのデータを反転して生成、時刻表も自動生成）
- **駅レイアウト**: 桜ヶ丘・白浜台・岬口は島式2面4線の高架駅。それ以外は相対式2面2線を基本とし、羽根町に本線より低い階の支線ホーム、海浜公園に片側副線と旧駅舎風の正面を追加。仮駅や実物の細部を完全再現したものではない
- **待避**: 普通は2面4線駅で外側の待避線を使い、ドアを右側に開く。急行・特急は本線側を使う。分岐器制限45km/h、場内信号は注意現示と進路表示。白浜台で普通が後続の急行の通過を待つ。優等列車は普通の停車後に到着し、出口分岐器を抜けて見えなくなると出発信号が進行になる
- **記録**: 記録タブに自己ベスト（種別×区間）と最近のプレイ20件。リセットボタンあり。前回選んだ種別・車両・区間を覚える
- **運転**: マスコン P1〜P5 / N / B1〜B8 / EB。ブレーキ立ち上がり遅れ・走行抵抗・勾配抵抗・天候による粘着低下
- **信号・ATS**: 4灯式（R / Y 45 / YG 65 / G）。見えない先行列車の在線で現示が変わる。制限超過や停止信号接近で ATS 警報 → 5秒以内に B4 以上＋確認（`A`）が無ければ非常制動。停止信号冒進も非常制動
- **汐風線の終着進入**: 往復ともコース終着駅の手前1kmから連続速度照査。残り1000mで65km/h、600mで45、300mで35、120mで25、50mで15、停止位置で10を結ぶ速度パターンを表示し、3km/hを超える超過で即時非常制動。終着でも停止位置に正確に止める必要がある。実路線のATS照査値の再現ではない。モデルの泉大津・堺は本線途中駅なので車止めは置かない
- **駅**: 始発駅もドアが開いた状態から始まり、発車メロディ → 戸閉め（チャイムと閉扉音の約3.5秒は発車不可、閉まり切ると戸閉灯）→ 出発信号が進行なら力行で発車。定刻に閉まり切るよう戸閉めする。途中駅も同じ。通過駅で止まると減点
- **時刻表**: `npm run timetable` が両路線の種別ごとの自動運転から到着・通過時刻を計算し、走行時間に+5%の余裕を足す。汐風線は終着の速度照査も計算に含める。`npm run timetable -- --shiokaze-only` は汐風線だけ再生成し、山岳線の時刻表を変更しない
- **時計**: 時間帯に合わせて始発時刻が変わる（朝 7:30 / 昼 10:00 / 夕 17:30 / 夜 21:30。時刻表は相対時刻のまま平行移動）
- **ステージとモード**: 選んだ種別の停車駅間ごと＋全線通し。モードは 通常 / 遅延回復（遅れて発車）/ 定時運転（時間と安全のみ採点）。自己ベストは種別ごと
- **採点**: 停止位置・定時・安全（速度超過・EB・停車時衝動・ATS・誤停車で減点）。駅ごとの結果表、自己ベストを localStorage に保存。停止位置±0.3m で「ピッタリ」、15m 超の行き過ぎで失格
- **リプレイと視点**: 結果画面で `R` を押すと沿線カメラ・追従・空撮を切り替えるリプレイ。運転・停車中は `V` で 運転台 → 俯瞰追従 → 前方斜め → 編成全景。俯瞰追従・リプレイは従来の配置を保持。側面アップを、顔と側面を見る前方斜め、編成全体を見る全景へ変更。全景は編成長・曲線・勾配・画面比率に応じて距離を調整する。
- **車両プレビュー**: 車両タブに実モデルから描いた顔アイコンと3D外観展示。正面・斜め・側面・屋根、回転・拡大縮小、先頭車 / 選択編成の全体を切り替えられる。展示は昼の照明で、ゲーム側の天候や車両材質は変更しない。展示が見えている時だけ必要に応じて描画する。
- **環境**: 時間帯（朝・昼・夕・夜）と天候（晴れ・雨・雪・霧、強さ可変）。スカイドーム・太陽と月・星・雲、影、窓の雨粒とワイパー、積雪、トンネル内の暗転。夜は前照灯・ホーム照明・沿線の街灯・窓明かりが点灯し、時間帯の切替に合わせて連続的に変化する。画質は 低 / 中 / 高
- **ビジュアル**: 20m 級4扉の通勤電車（架空塗装）を手続き生成（自列車・対向列車）。3D 運転台（マスコン・速度計・圧力計・戸閉灯・行路表が連動）。日本の街並み（戸建て・アパート・マンション・商店・架空のコンビニ・自販機・電柱と電線・田畑・竹林）、踏切（遮断かん・警報灯が連動、待機車両）、トンネル坑口・高架橋・橋梁と川。駅前ビルと木は CC0 の 3D 素材
- **音（すべてコード合成。録音サンプル不使用）**
  - VVVF: 非同期 → 同期 27P/15P/9P/5P/3P → 1パルスの音程階段、電動機の高調波、歯車音。回生ブレーキは逆順、5km/h付近で失効。改良音は低い起動音から立ち上げ、高域の倍音・2.8kHz付近・歯車音を抑え、低いうなりと加速に伴う音量変化を調整。停止中に力行を入れただけでは高い音を立ち上げない。サウンドタブの「走行音」で改良（既定）/ 従来を比較でき、選択は保存。実車の録音や制御値の再現ではなく独自合成（VVVF車のみ対象）
  - 走行音: 転動音・風切り・高架の空洞音・急曲線のフランジ音。継ぎ目は台車配置どおりにタタン・タタン。トンネルは ConvolverNode 残響
  - 空気ブレーキ・コンプレッサ・ブレーキ鳴き、ドアチャイム・ドア開閉・オリジナル発車メロディ・ホームのざわめき
  - 車内放送: Web Speech API（ja-JP 音声がある環境のみ。無ければ無音）。声は端末（ブラウザ・OS）の日本語音声に任せる（加工しない）。駅名はカタカナで渡して読み間違いを防ぐ。始発駅の発車後は挨拶と行先、終点の手前は御礼、普通は待避駅で「待ち合わせ / 通過待ち」と発車時の「お待たせしました」、急行は接続駅で「普通車にお乗り換えになれます」
  - ATS ベル/ブザー、速度超過ブザー、空気笛、踏切警報（距離減衰・ドップラー）、雨音、すれ違い
- **描画負荷の工夫**: 手続き生成物は材質ごとに結合（300m チャンク）、読込素材は材質ごとの `BatchedMesh` に集約（個体単位の視錐台カリング）、木は距離で簡易形状へ切替、遠方のチャンク・枕木・標識・信号・踏切は距離で非表示。描画コールは中画質で約 110〜180（影パス込み）

## 操作

### 描画比較（試作）

画面左下の「描画：イラスト / 標準」で即切替。走行状態・時間帯・天候は保持する。
イラスト描画は柔らかな3段階の直射光、冷色の環境光、車体の細い輪郭線と縁の陰影、地面の濃淡、建物の接地影、遠景の霞を追加する。
夜・トンネルでは効果を弱める。モデル・信号色・運転処理は変更しない。

- イラスト（既定）: `http://localhost:8765/?look=illustrated`
- 元の描画: `http://localhost:8765/?look=standard`
- 実装: `src/render/illustrated.ts`。依存追加なし。
- ソースごと戻す場合: `main.ts` の `attachIllustratedLook` の import・呼出しを外し、`town-jp.ts` の `shadowChunks`・接地影生成/配置と `train-models.ts` の `train-shell` 命名を戻す。この節と追加ファイルも不要になる。今回の追加は1つのコミットにまとめてあるため、そのコミットを revert すれば車両展示・視点変更も含めて元へ戻せる。

| キー | 動作 | 場面 |
| --- | --- | --- |
| `↑` / `W` | 力行側へ1段 | 走行中 |
| `↓` / `S` | ブレーキ側へ1段 | 走行中 |
| `N` | ノッチオフ | 走行中 |
| `Space` | 非常ブレーキ（減点） | 走行中 |
| `A` | ATS 確認（B4 以上で）/ 停止後の復帰 | 走行中 |
| `H` | 警笛（長押し） | いつでも |
| `V` | 視点切替（運転台 → 俯瞰追従 → 前方斜め → 編成全景） | 運転・停車中 |
| `X` | ワイパー ON/OFF | いつでも |
| `M` | 消音 切替 | いつでも |
| `Shift`+`T` / `Shift`+`Y` / `Shift`+`Q` | 時間帯 / 天候 / 画質を切替 | いつでも |
| `Enter`（または `Space`） | 出発 / もう一度 | タイトル・結果 |
| `Tab`（または `K`） | 種別選択（普通 → 急行 → 特急） | タイトル |
| `←` / `→` | ステージ選択 | タイトル |
| `↑` / `↓` | モード選択 | タイトル |
| `R` | リプレイ開始/停止 | 結果 |
| `Esc` / `T` | タイトルへ | 結果 |

- タイトル画面は路線・方向選択と「ステージ」「車両」「環境」「サウンド」「操作」「記録」のタブ。環境（時間帯・天候・強さ・画質）、音量、VVVF走行音の改良/従来設定は localStorage に保存
- ゲームパッド（standard mapping）: 十字上下・LB/RB でノッチ（タイトルでは LB/RB で種別、十字でステージ・モード）、A で開始・ATS確認、B で EB、X でノッチオフ、Y で視点、Back でリプレイ、L3 で1軸レバーモード
- タッチ端末は画面右下のボタン（力行・ブレーキ・ATS・EB・視点）

## 実行方法

```bash
cd apps/densha-one-station
npm install
npm run dev        # 開発サーバー（http://localhost:8765）
npm run typecheck  # 型チェック
npm run verify:routes # 汐風線6運行・山岳線2運行、終着ATS・ホーム直線・橋梁非干渉の回帰確認
npm run build      # dist/ へ本番ビルド（base: './' のため GitHub Pages のサブパスでも動作）
npm run preview    # ビルド結果の確認
```

開発時の `?inspect=1` は駅・跨線橋・支線の景観確認画面。`&route=shiokaze-up` で復路を確認できる。本番ビルドでは読み込まない。
終着ATSは残り1500mで予告し、1000mから速度照査を開始する。

並行作業用に `.claude/launch.json`（worktree ルート）へ `densha`(8765) / `densha-a`〜`densha-d`(8771〜8774) を定義。開発時は `window.__densha` で GameContext を参照できる。

旧単一ファイル版は `legacy/index.html`（参照用。CDN import map 版でそのままブラウザで開ける）。

### 公開用リポジトリの更新

公開は、このディレクトリの中身をルートに置いた独立の公開 repo で行う（この個人 repo からは直接公開しない）。

1. このディレクトリを公開 repo へコピー（`node_modules/` と `dist/` は除く）
2. `deploy/pages.yml` を公開 repo の `.github/workflows/pages.yml` として置く
3. 公開 repo の Settings > Pages > Source を「GitHub Actions」にする
4. 公開 repo の `main` へ push すると `npm ci && npm run build` → `dist/` が GitHub Pages へ公開される

## 公開可否

可。3D素材はすべて CC0（帰属表示不要だが出典を記載）。ゲーム内の駅名・路線名・店名・塗装は架空。汐風線は実在する南海本線の区間を参考にした概形で、公式の再現・監修ではない。調査資料に実在の駅名・事業者名を出典として記載するが、公式ロゴや実車録音は収録しない。
